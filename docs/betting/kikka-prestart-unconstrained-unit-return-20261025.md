## 数理ルール（全券種に同じ着順分布）

単勝オッズoから、馬iの強度を w_i=o_i^(−γ)、勝率p_i=w_i/sum(w) とする。γ=0.75/1/1.25を**未推定**の感度として並列比較。別途10/24に**正式封印したM1勝率配列**をそのままPlackett–Luce順位確率へ変換して比較する。元封印M1は上書きしない。

全18×17×16=4896順序付きトップ3着順を厳密列挙。単勝、複勝（Top3）、枠連、馬連、ワイド、馬単、三連複、三連単へ確率質量を整合的に集計。券種ごとに `expected_gross_per_unit = p_model(event) * quoted_intermediate_odds_low` と定義。下限複勝・ワイド配当は確定額ではないため、現実の払戻期待値とは一致しない。

**単勝M0(γ=1)の定理的な限界：** p_i=o_i^(−1)/sum_j o_j^(−1) なので p_i*o_i = 1/sum_j(1/o_j) は全18馬で等しい。今回の逆単勝表示オッズ合計は約**1.2772**、よって全18頭とも**0.78295倍**。M0単勝から割安馬は定義上選べない。

## 現時点の妥当な解釈

- **能力順位**は⑧を中心に⑩、その後⑨・⑤・③・②。順位は当日市場M0由来で、独立実績による真の勝率校正は未実施。
- **掲載分で最高p×オッズ**は馬単④→⑩（2.431）だが、γ=1.25では0.924に落ちる。強い結論ではない。
- **仮定間での数値安定性**は三連単⑬→⑧→⑩、⑯→⑧→⑩、三連複⑧–⑩–⑫など。ただし低的中率・稀な事象の確率誤差は巨大になり得る。
- 金額制限がないまま最適投票金額を求めることは数学的に無定義。真のEVが正だと仮定すれば金額増で期待利益は際限なく増す。実際には予算、価格変動、控除率、許容損失、リスクと校正誤差が必要。ユーザーが指定しない限り金額・投票比率を勝手に決めない。
- 前向き確認は結果判明後に事前封印M1−M0の勝馬Log loss・Top3 Brierを採点する。その結果を使って今回のモデル係数を後付け修正しない。
