# 天皇賞2026：市場の「転換」は本物か、臨界的な自己強化か

**Source-declared quoted-price analysis, 2026-10-31.** [PR #38](https://github.com/zuizui0223/keiba/pull/38) の記事中5時点・上位4〜5頭のみを再解析する。JRA-VAN元時刻受信・全17頭時系列・馬の実GPS・個人投票の観測ではない。記事の過去取得時刻は編集者自己申告であり、第三者により完全認証された市場更新時計ではない。

## 一つ進んだ実測的問い

PR38 は公開表示価格の1位・2位が⑦→①→⑦と変わることを確認した。ここでは単に順位が入れ替わったかではなく、

> **同じ日の馬間相対価格は、一方向にしか動かない過程でも説明できるのか。測定丸めを考慮しても、その方向転換が必須になるのか。**

を問う。

[Race Postmanの10/31追記記事](https://race-postman.hateblo.jp/entry/2026/10/31/061338) に記載された①③⑦⑪⑰の時間別単勝価格を、既存の [PR38のcanonical source SHA](../../scripts/keiba_tenno_partial_article_timepath.py) に固定したまま使用。06:08は①③⑦⑪の4頭だけ。08:09以降は①③⑦⑪⑰の5頭だけ。全部で4+5+5+5+5の**部分観測**。他の12〜13頭のオッズを創作したり、部分集合を全17頭の勝率のように正規化したりしない。**観測ペアは10組、独立競走は1件**。

## 「丸め方」を前提で決めずに3種類を比較

表示オッズ d が小数1桁のとき、潜在オッズの仮定集合をそれぞれ

| 感度条件 | 許容する潜在オッズ |
| --- | --- |
| 四捨五入を仮定 | [d−0.05, d+0.05] |
| 小数1桁の切り捨てを仮定 | [d, d+0.10] |
| 両仮定の和集合を覆う保守的な区間 | [d−0.05, d+0.10] |

とする。実際のJRA時系列の真の内部精度・表示処理をこの資料だけで証明できない。JRA-VAN製TARGETマニュアルは、オッズから票数を逆算するときに原過程の**端数切り捨て**による誤差が残り、特に低オッズの人気馬で誤差が大きいと注意している（[公式に公開されたTARGETマニュアル](https://targetfaq.jra-van.jp/faq/detail?category=103&id=256&site=SVKNEGBV)）。したがって四捨五入だけを「既知のJRA計算則」と扱わない。

2頭 i,j の log 相対価格 z=log(o_i/o_j) の下界・上界は、両馬の許容価格を [Li,Ui], [Lj,Uj] として、正確に [log(Li/Uj), log(Ui/Lj)] になる。

すべての観測時点で**単調増加**の潜在 z(t) が存在するためには、任意の早い観測 s と遅い観測 t について lower(s) ≤ upper(t) でなければならない。逆に**単調減少**には、upper(s) ≥ lower(t) が必要。この条件は区間ごとに任意の潜在値を選べるという設定では必要十分である。両方の方向が不可能なら、どこかで価格変化の方向が変わったことが数学的に必要。

## 事前に記述した数値比較（ソース内5時点）

| 表示誤差条件 | 単調増加でも単調減少でも説明できないペア |
| --- | ---: |
| 四捨五入を仮定 | 8 / 10 |
| 切り捨てを仮定 | 8 / 10 |
| **両方を覆う広い区間** | **6 / 10** |

この6ペアは **①–③、①–⑦、①–⑰、③–⑦、⑦–⑪、⑦–⑰**。それぞれ元記事に記載された時点だけを比較しており、⑰を含む比較は06:08を含まない。同じ5頭から作った依存する10組であり、「6/10」という値に独立Bernoulli試行やp値の意味はない。

①と⑦の中心値を log(o1/o7) とすると、08:09は+0.0800、12:07は−0.1484、13:08は−0.0364。

**08:09 → 12:07 → 13:08 の下向きから上向きの変化は、3つの誤差モデルでそれぞれ厳密に必要**になる。異なる時点の潜在価格をすべて最も有利に選んでも、下向きの最小変化量、反発の最小変化量は以下となる。

| 計算上の表示誤差条件 | log比の下降の最低量 | log比の反発の最低量 |
| --- | ---: | ---: |
| 四捨五入 | 0.151231 | 0.038466 |
| 切り捨て | 0.148420 | 0.037740 |
| **広い区間** | **0.111610** | **0.001656** |

広い区間で反発の厳密な最低量は小さいため、表示処理により未知の追加誤差があれば消え得る。あくまで定義した誤差集合に条件づけられる結論であり、真の市場の内部的な取引レベルで同じ現象を観測した証明ではない。また08:09→12:07の238分、12:07→13:08の61分は**記事著者が記載した時刻差**。これで割って求める変化速度は原市場の実更新速度ではない。

## 三つの機構を「当てはめたら説明できる」と言ってはいけない

この資料だけで原過程の機構が識別できないことも、再現可能なモデルとして明示する。

1. **滑らかで向きが変わる連続過程。** 観測点の log 相対価格を、各区間で端点の微分1次・2次が0の五次smoothstepで結べば、全点を通る **C2連続曲線** が必ず構築できる。飛びは必要ない。拒否されたのは「単調な固定方向ドリフト」であって、平均回帰・拡散を含む普通の滑らかな変動ではない。
2. **外部イベントによる不連続変化。** 観測時点で価格が更新されたことにして区間内を階段状にすれば全点を通る。しかし本当にその時刻に外部情報が来たかは証明できない。
3. **自己強化・情報追随を想定する過程。** 隣接点の log 比差を Δz とし、人工的に Δz_t = φΔz_(t−1) + ε_t と置いても、φ=0、0.5、0.9のどれについても**残差 ε を自由に選べば全点に誤差ゼロで一致する**。これは自己強化が見つかったのではなく、外部イノベーションの事前制約がなければ係数φは**全く識別できない**という構成的反証。

3つがすべて同じ観測点を誤差ゼロで説明できるため、**現データの「逆転」そのものは自己強化・急変を選択する根拠にならない**。
