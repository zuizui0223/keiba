# 同一馬の反復GPS個体効果 → 馬ABM/PDE → 投票者ABM → 市場安定性

**2026-10-26: SYNTHETIC ONLY／実馬・実市場の因果接続は未実証。**

本実験は親[PR #24](https://github.com/zuizui0223/keiba/pull/24)の上に積む新規Draftブランチで、main・v3.1・2026菊花賞の封印M0/M1/M2・既存PRを変更しない。

## どこが新しいか

従来の馬ABMの能力初期値は最初の表示単勝を逆数正規化した市場指数 q0 またはJRAの過去着順を使った未校正form priorであり、**同一馬のGPS区間時間から推定した個体別反復効果は使っていなかった。**

現mainの独立した生態学分析ではRQ Cannon Parkのレース固定馬ID ICC約0.430、36頭・46後続記録で自馬履歴RMSE 0.255809秒 vs 他馬履歴0.303195秒を得た。ただしICCの対象はレース固定した初回GPS区間の絶対秒数、RMSEの対象は他の同レースGPS観測馬との差という異なるアウトカム。この0.430をJRA馬の速度へ直接代入しない。

## 今回結合した五階層

### 1. 同じ馬の反復測定から実験用個体効果を推定

新規 [Python実装](../../scripts/keiba_individual_trait_to_market_cascade.py) で、同じsource_system、同一HORSE ID、GPS first marker、公式距離、Class、**過去の日付と受信時刻**を厳密照合。同一条件で最低3日・5反復馬・4GPS観測馬/レースが必要。異なるRQ/JRA馬IDの同一視、情報取得後の時刻の捏造、発走後アウトカム利用は拒否する。

測定対象は馬の初回GPS秒数から**同じレース内の他GPS馬平均**を引いた相対量 y_ir。各馬の複数日の相対タイムから馬別事後平均 a_i、馬別不確実性、探索的な馬間分散 v_a と残差分散 v_e をmethod-of-moments＋正規縮約で求める。

- k_i = n_i × v_a / (n_i × v_a + v_e)
- a_hat_i = k_i × mean(y_ir)
- posterior_var_i = v_a × v_e / (n_i × v_a + v_e)
- experimental_ICC = v_a / (v_a + v_e)

これは生態学mainのレース固定REMLと同じ推定器ではなく、遺伝率・生得的性格・因果的競争反応を表さない。元データの受信済みというローカル自己申告は外部の真正証明ではない。

### 2. 客観的馬状態と初期市場支持を独立に定義

objective_i ∝ exp(−κ × a_hat_i + β × prestart_covariates_i) とし、独立した初期能力情報を組み立てる。κ、βは**未校正のシナリオ係数**。馬場・天気・騎手・距離の共変量は今後**元の公開時刻が初期市場の観測より先である**ことを検証して与える必要があり、今回は実際の係数を学習していない。

これと異なり、q0_i ∝ 1 / 初回表示単勝オッズ_i は**既に人間の判断と市場価格形成を含む、非確率校正の代理支持指数**。q0を変更しても馬のobjective_iや馬の物理ABMシグナルが変わらないことをテスト。最初に観測された市場を「純粋な客観状態」と誤認しない。

### 3. 物理馬ABMと因子化PDEへ同じ独立馬priorを渡す

新モジュールから既存[非局所馬ABM/PDE](../../scripts/keiba_nonlocal_horse_pde_bettor_bridge.py)の実装関数 finish_pair / pde_density_and_agent_check を実際に呼ぶ。馬ごとの独立priorはシナリオとしてGumbel＋Brownianを伴う初通過競走に渡され、前方8m・減衰3mの同じカーネルを使う。c=0とc=2の仮想混雑シナリオを共通乱数で比較する。

16.8m/sの定数、変換係数、D=0.25m²/s、混雑c=2は現実の競走馬で実測・校正していない。PDEは有限馬の相関を無視した**周辺密度因子化近似**であり、真の集団運動の実測モデルだとは呼ばない。

### 4. 投票者の情報階層と経路依存を明示

三種類の仮想投票者を別に定義：

1. fundamental: 自身のobjective_iのみで選択（市場評価に追随しない）。
2. herding: 現在の市場指数 q_i(t)^γ_social で選択する。
3. informed: 馬の客観priorのみで判断し、**登録したラウンド以後**、公開された仮想馬シグナルを反映する。

新票は累積プールに加算され、次の支持指数q(t)が生成される。現在のq(t)が次の投票者の判断材料になるので、市場の自己参照的記憶が表現される。同じhorse signalを情報公開前だけ変えても、そこより前の市場経路は**完全一致**する負対照を検証。実投票者の個票、販売額、投票動機を観測したわけではない。

### 5. 「臨界オッズ」は固定倍率でなく、自己参照増幅率として扱う

均一の客観評価と均一の公開情報を仮定した均一固定点の決定論的市場更新に対し、herding人口比 f_H、新票の最終占有率λ、herding exponent γ_social としたとき、確率単体の接空間での線形増幅率は

G = (1−λ) + λ × f_H × γ_social

である。λ>0、f_H>0で中立になる条件はγ_social=1/f_H。例えばf_H=0.5でγ=2が中立。これは**仮想市場での局所的な数学的安定性**であり、「単勝10倍で相転移」の証拠ではない。γ_socialは勝率のPL市場集中度γ_winとも別のパラメータ。

任意のqでの数値Jacobianを単体接空間へ射影する関数 local_market_gain も実装した。ただしqが固定点でない場合、その値は局所応答の感度であり、相転移・分岐判定ではない。現在のオッズ市場に実在する臨界点は**未識別**。

## 反証試験と結果の限界

[新しい人工テスト](../../tests/test_keiba_individual_trait_to_market_cascade.py) は、反復馬別差を意図的に注入した架空GPSで、個体効果推定、元馬ID・時刻・マーカー一致、初期市場評価からの完全分離、同じsourceのABM/PDE呼出、情報公開前の市場への漏洩なし、非混雑・混雑差、臨界増幅の数値Jacobianと解析式の一致を検証。

**すべて人工データでの計算の成立性であり、実馬に個体間反応規範があった／実投票が臨界状態に達したという証拠ではない。** サンプルは6頭・6日などの完全架空構成であり、独立した実市場次時点の予測精度、真の投票量、校正勝率、賭け金利益は一切算出しない。

## 次に必要な実測データと事前判断

1. 同じ競馬データ源内の同一馬・同じGPS marker・距離・Classを反復観測し、別開催日で個体効果と予測を検証。原 source のGPS欠測と出走分母を記録。Racing Queenslandの馬IDをJRAの馬番に付け替えない。
2. 最初の市場オッズより前に公表された実馬場、天候、騎手、馬体状態、実測馬の個体履歴から客観モデルの係数を**前の開催日だけ**で学習する。その上で最初のオッズに含まれる集団判断の追加情報を比較する。
3. PR #24の対象26競走の次オッズ価格時系列は、事前固定分母、私的な権利・時計検査、外部SHAコメントを使って未来価格公開前に封印する。現段階の将来実測次市場スコアは0件。
4. 固定しきい値、滑らかな追随、投票量/過分散/価格観測時計の帰無を対置し、十分な別開催日で情報増幅の境界を検証する。モデル内に初期10倍や0.10/時を置くだけでは情報的相転移を発見したことにはならない。

**学術的位置づけ:** 個体行動の定量生態学を、社会物理・市場の自己参照情報ダイナミクスへ接続する、反証可能な**数理生成モデルの方法論段階**。実馬の因果機構・観測者の個票・社会的追随・臨界オッズ・正の馬券期待値の実証はHOLD。


## 2026-10-26: 完全人工の反復馬デモと偽陽性防止

[デモ実装](../../scripts/keiba_individual_trait_market_demo.py) は同じ6頭・7競走の作り物のGPS初区間時間に、意図的な馬別安定成分を注入する。新しい機構の入力には **履歴のsource受信・初回市場の公表/受信・予測時刻**をすべて明記する。追加の [ローカル事前客観特徴量ゲート](../../scripts/keiba_individual_trait_to_market_cascade.py) では、天候・馬場・騎手等の履歴係数モデル凍結時刻、特徴量公表時刻と受信時刻が初市場の公表時刻よりも早い必要があり、odds/market/target_finishを入力に含むものを拒否。これは自己申告sourceの時刻論理検査で、外部真正証明ではない。
