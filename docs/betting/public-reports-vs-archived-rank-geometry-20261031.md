# 馬券市場の「順位逆転」と群衆の「動的閾値」は別の現象：実オッズ原表の検証

**2026-10-31 記述的実測＋既存の固定原ソース再監査。** 予測済み勝率の検証・群衆の臨界性・賭けの優位性ではない。親 [PR #34](https://github.com/zuizui0223/keiba/pull/34) の17頭M0価格変化の反実仮想に、初めて別公開記事の17頭比較表および既存京都の源泉SHA固定時系列を対応させる。

## データ1：天皇賞（秋）の別媒体記事、まず時計を検証

1. **10/31 17:00と記事が明示：** [競馬TIMESの17頭「前日単勝」列](https://keiba-times.com/tennosho-aki-2026-zenjitsu-odds/)。編集部の**予想オッズ列は入れない**。親PR33/34の固定値と元宣言SHAをそのまま再使用。
2. **10/31 18:00と記事が記載：** [ウマニティの全17頭](https://umanity.jp/racedata/race_newsdet.php?nid=11881172)。独立した編集媒体、17頭全件のオッズを明示。記事で記載した参照時刻をデータ配信の真正時刻と取り違えない。
3. **重大な反証：** [netkeibaの17:42公開記事](https://news.netkeiba.com/?no=347359&pid=news_view) は、ウマニティの名目18:00記事と**全17頭のオッズが完全に同一**。従って**18:00に新規更新された市場の値だと認証できない**。18:00と17:00を差し引き60分の実投票変化速度と報告してはならない。両者はともにJRAを出典とするが、一次feedの元バイト／provider source_updated_at／local received_at／票量／タイムスタンプの第三者証明はない。

17:00の元価格列は親PRの既存 SHA 固定値。名目18:00記事表はUTF-8 canonical JSON の宣言SHA **3b8fc4798664a090963d5e8221029643cf9205934ba7fe7db0cc37a8d1f6e37b** で固定。これらは**研究コード内の誤改変対策**であり、記事の真正原本受領・合法なJRA-VAN CSVを証明するものではない。

### 数値結果：17頭の2記事間の差（同一feedの時系列とは認めない）

## データ2：京都2026-10-12の公表済み元オッズ時系列

既存の immutable SHA [SOURCE_SHA](../../scripts/odds_real_multirace_archive_audit.py) をそのまま再使用し、京都8～12Rそれぞれの**同一系列**の2時点を比較する（独立**5競走、同一開催日1日、時間区間5**）。さらに8Rだけ保存済みの第三点（13:26→13:44）を1区間追加する。よって**価格変化の区間は合計6つだが、6つの独立競走ではない**。独立検証データや真正前向きSHAコメントは増えない。

コードは元のsource SHA・馬番全件・市場更新時間・原本受領時計・発走前条件・providerを検査。既存の [R8 source-locked three-point audit](../../scripts/odds_r8_real_three_time_market.py) から**出走結果の呼び出しを行わない**関数だけ使う。馬ごとの原GPS、元票数、事後結果は使用しない。結果はGitHub Actions artifactに集計として保存し、親PR14–20の閾値モデル・PR22–32の真正次価格取り込みと混ぜない。

証拠：[GitHub専用CI #41195107451](https://github.com/zuizui0223/keiba/actions/runs/41195107451) に9テスト成功・同じ数値を出した実行ログがある。このPRはmain・元封印済み事前予測とは別のDraftであり、**これらは元レースの時刻を過ぎてから行った再解析**であって真の前向き予測精度ではない。

## 科学的問いへの接続

静的な時点間順位差は、**実数のオッズが滑らかに動くだけで生じ得る**。親PR34が示した同順位になる必要十分の対数差は、今回の観測各区間でも必ず確認できる。しかし、価格が臨界値を越えて集団行動が自己強化したかどうかには、**順位逆転の有無とは異なる証拠**が必要。

検証の正しい順序：

1. まず同じproviderから**全頭が揃い、原資料が時刻証明され、初回・次回・将来targetが区別された**真の市場データを合法的に取得する（PR30/32）。現在の天皇賞2記事だけではこのゲートを満たさない。
2. 元時刻・時計と全件取得が検証された各競走の前方データだけで、**持続・連続応答・急変応答**のパラメータを凍結して将来q2を予測。**馬の過去行動・馬ABM・非局所PDE・投票者ABM**を接続する場合、時刻が保証された独立した馬履歴が存在する条件を別に明示する。
3. 市場支持指数のTV/KLを、競走単位かつ開催日を意識して将来採点。閾値なしモデルの予測改善と、ノー情報帰無下での見かけのゲート発火率を同時に評価。見かけの順位交差は機構証拠から除外する。

**今回の成果：実際の価格表の違いを測ることはできた。ただし18時の新規投票更新を実証したわけではない。過去の京都時系列を使うことで、順位幾何学の応用範囲を競走間へ広げられる。**
