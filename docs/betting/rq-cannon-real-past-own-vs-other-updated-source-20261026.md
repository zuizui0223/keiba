# 実馬Cannon Park：自馬の過去GPS履歴と他馬履歴の予測力を、更新された元ソースで再検証

**実行日：2026-10-26。新たな独立馬群ではなく、これまで固定していた同じ12開催日のソース版比較。**

## 目的と重要な結果

Racing Queenslandが公開した元の公式HORSES IDと初期GPS区間秒数について、旧mainの`ecology_rq_forward_alternative_history.py`で**事前に固定された**方法を、最新版として再取得した12/12開催日のデータに再適用した。差の符号が維持されるかを調べ、`old 543 candidate source edition`と`updated 526 candidate source edition`の違いを見える化する。

全ての馬ID、馬名、GPS秒数、騎手/調教師ライセンスはCI内でのみ扱い、GitHubの出力は**匿名集計だけ**。データはすべてレース後の記録であり、当時の投票が始まる前に見られた情報とは主張しない。

主要比較の改善率は**15.34%**、Classも合わせた20頭の比較では**17.38%**。このRMSEは同一馬ごとに誤差を先に平均した馬ID均等重みであり、**同じ未来観測行**について自馬と他馬の履歴モデルを比較。固定の履歴平均の縮約係数は `n/(n+2)`。必ず対象日より**前の別開催日**のGPS記録だけで評価を作り、対象日に得られたGPSを翌日に初めて学習へ追加した。

基準は「異なるsource Jockey/@Idが当該馬に過去同条件では一度も記録されていないこと」。**実際に騎手が変更された事実を確認したものではない**。他馬一般／同調教師／同騎手の比較は**別々の対象集団**なので、改善率の大小を調教師効果・騎手効果と解釈できない。

**2026-10-14 source edition（543候補行）では**：同距離・同マーカーの一般対照は **36馬ID／46後続観測**、自馬0.255809秒 vs 他馬0.303195秒（改善+0.047386秒、15.63%）。今回の最新版は35馬ID／44観測で符号とほぼ同じ規模を維持。これは**同じsource期間内でソース版を変えた感度**であり、外部データによる独立再現ではない。

## ここから言えることと言えないこと

**実測で支持：** この固定されたCannon Park 2026ソースのGPS観測馬について、馬IDに結びつく反復成分が残り、同じ馬の過去相対的な初期区間行動が、他馬の履歴より後続の相対区間時間をよく予測する。複数のソース版で符号・概略規模が維持され、独立数値REMLも一致した。

**未同定：** 先天的/遺伝的な性格、馬場別の反応規範、ライバルからの因果効果、GPSに入らなかった全出走馬、実際の確定騎手、完全レースの着順・全距離タイム、対象初期オッズより早く公開されていた個体GPS、Racing Queensland馬とJRA別馬番の同一個体性、実投票の追随係数、臨界オッズ、実市場予測・馬券収益。**上記の相対GPS目標は他の同レース測定馬のタイムを参照するため、馬の絶対速度・物理的相互作用を直接測った結果ではない。**

同レースの`mark 150m vs 250m`を別の測定形質として扱う追試もDraft PR #29に実装し、ソースが十分でなければ個別に**HOLD**とする。後から観測結果に合わせたマーカー・日付・馬の選択は禁止。
