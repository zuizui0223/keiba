# Source-only REML → 馬の反復可能な個体効果 → 非局所ABM/PDE → 情報型投票者市場

**2026-10-26 実装・人工モデルの反証監査 / Draft PR #26。** 既存のJRA発走前予測、正式v3.1、旧PRの予測SHA、mainは更新しない。本ページのすべての具体的数値は**完全に架空の馬6頭と過去7レース**から生成された数理実験であり、Racing Queensland / JRAの真の個体効果・馬場適性・オッズ現象を新しく実測したものではない。

## 1. なぜ固定した分散をやめるか

[前回の馬間相関接続](horse-race-contrast-joint-trait-market-20261026.md)は、絶対時間からレース平均を取り除き、馬間の誤差共分散を使った条件付きGaussian posteriorを導入した。ただしその条件付けに必要な馬間分散 a2 と独立残差分散 e2 は、同一レース他馬平均との差から求めた粗いmethod-of-moments値を **独立な絶対時間残差の分散として流用**していた。

新しい[source-only Gaussian REML](../../scripts/keiba_source_race_fixed_reml.py)では、最初のGPS区間の**元の絶対秒数**からレースごとの平均を直交コントラストで取り除き、対象レースの結果も、初期・後続市場オッズも使用せず、元の過去GPS履歴だけで分散を推定する。

各レース r の初回区間秒数を
t_r = μ_r 1 + Z_r a + ε_r, a∼N(0,a2 I), ε_r∼N(0,e2 I)
とする。レース内のHelmert行列 Q_r は Q_r 1=0, Q_r Q_r'=I_{n_r−1}。重ねた z=Q t, B=Q Z のrestricted likelihoodは

Cov(z) = e2 I + a2 BB'

となる。比 ρ=a2/e2 と BB' の正の固有値 λ_k から、e2を消去したprofile objectveを

L(ρ) = m log{z'(I+ρ BB')^(−1) z/m} + Σ_k log(1+ρ λ_k)

として1変数で最小化（m=Σ_r(n_r−1)）。線形代数はNumPyだけで行う。数値探索の端、個体分散ゼロ境界、識別情報不足、非有限値、対象レースの未来GPS、異ソースIDは**明示的なHOLD**となり、正の分散をでっち上げない。

### main のRacing Queensland生態学REMLとの独立な数学的検算

source-only版の推定式は既存の main 生態学解析 scripts/ecology_rq_race_fixed_icc.py と同じレース固定・馬IDランダム切片モデルを使う。計算コードは独立で、新版はNumPyのみ、mainはSciPy Helmert・eigh・minimize_scalarを使用。

**人工24頭×12開催日の同じ元絶対タイム**を渡した照合では、馬間分散、残差分散、調整ICCが事前の数値許容差内で一致。専用Actions runnerが main commit 43e0fe30e0a2b976614b5b73bf889480a8e45c1c から、ソースblob SHA 185249dc9c6a9c4bb3f9699e9c4370147fed0ff0 および eedf02fb730c82fb08ff2e96a67710896c54fb06 の**2ファイルだけを検証用に取得**。PR #26へ main の全生態学スクリプトを複製しない。独立比較の詳細は[人工検証テスト](../../tests/test_keiba_source_reml_vs_ecology_main.py)。

**注意：** 同じ数理手法の出力一致であり、実RQデータの再推定成功・新しい馬の遺伝率・競走環境への適応を確認したわけではない。

## 3. 不確実性が個体→ABM/PDE→市場へどう伝播するか

[相関を保つ同時事後分布](../../scripts/keiba_race_contrast_trait_posterior.py)に source_reml モードを追加。新たな[統合不確実性モデル](../../scripts/keiba_trait_uncertainty_ensemble.py)では、modeを race_contrast_covariance、variance_fit_modeを source_reml に指定し、推定された a2/e2 を同一馬IDの事後平均と共分散へ渡せる。

下記3つはprofile objectiveの差が2以内の ratioグリッドから選んだlow/central/highという**事前に計算した感度シナリオ**で、確率を付けた母集団の事後分布・95%信頼区間ではない。各シナリオに人工12回の個体効果draw×65馬ABM Monte Carloを用い、後半の客観→herding人口割合を変えた仮想投票者ABMへ渡した。

| Gaussian比の感度 | a2 (秒²) | e2 (秒²) | 混雑の有無で生じる仮想市場TV差（pp） |
|---|---:|---:|---:|
| low | 0.081539 | 0.018194 | **0.30417** |
| central | 0.135639 | 0.016254 | **0.30000** |
| high | 0.299401 | 0.014906 | **0.28750** |

**同じ個体性モデルでも、分散比の仮定を変えるだけで最終的な市場の応答が変わる。** ただし数値差の方向と大きさはこの人工条件固有である。最終まで馬の走行シグナルを投票者へ知らせない反事実では、**全3シナリオで市場TV差が厳密に0**。この「効果なし」はプログラムが未来の情報を過去へ漏らさない負の対照であり、実馬に情報効果がないという実証ではない。

## 4. 確率階層と「臨界オッズ」を混同しない

- 馬の個体差の分散 a2、競走の文脈、客観的馬場・距離・騎手などの事前情報により馬の客観予測 p_obj を生成する。馬場等の係数はまだ実データで学習していない。
- 最初に観測できた市場オッズ q0 は**すでに人間の投票・集団判断を含む**。客観馬priorに混ぜず、違う入出力として扱う。
- 馬ABM/PDEが作る走行分布を情報型投票者がいつ受け取るか制御する。物理予測signalは既に客観priorから計算しているため、signal×objectiveという客観証拠の二重計上をやめる。
- 後続市場は投票者ABMの累積票を介した自己参照過程として更新する。変化の早さが情報流入や社会的同調を証明するわけではない。
- 人工市場の均一固定点では、局所増幅率 G_t=(1−λ_t)+λ_t f_herd,t γ_social が1を越えるかで安定性を評価する。ただし現実の「単勝10倍」に臨界点が存在すると主張しない。前向きのJRA実投票量・外部情報時刻がないため実市場の臨界性はHOLD。

## 5. 次の本物の実測ゲート

1. 同一公開元の馬のHORSES IDと元のGPSセクショナル秒数が、**指定したターゲット競走の最初の市場公表より前**に実際に入手できたことを権利・受信時計込みで検証する。現source inputは自己申告真偽値だけで、その真正性は外部未検証。
2. ストラタ（GPSマーカー、公式距離、Class）の欠測選択を明示したうえで、race-fixed REMLの分散を再推定する。source datesは個票数ではなく独立なクラスターとして扱う。年を跨ぐ相関や個体×馬場の反応規範は未推定。
3. **同じ競馬地域・同じ馬IDの反復GPSと、その馬の実際のオッズ市場の同時系列**を揃える。Racing Queenslandの馬の遺伝子型/騎手、JRAの別馬番、実JRAオッズを無断でidentity joinしない。
4. 本当に実馬・市場が対応する前向き将来レースの数が積み重なった後、客観のみ→市場q0のみ→双方→双方＋独立馬ABM予測を**完全に凍結したスコア**で比較し、Null/shuffleを対照として同じ結果集合を採点する。

**結論：** 分散成分の固定仮定に依存していた統合数理モデルを、元の過去GPS絶対秒数を使うsource-only race-fixed REMLと複数profile感度へ拡張し、既存の生態学REMLとの計算整合性まで確認した。現実の馬−投票者因果、臨界オッズ、収益上の予測優位はまだ未検証である。
