# Racing Queensland実測GPS：相対初区間と絶対初区間を同じ後続個体で比較した日付ブロック感度

**2026-10-27 / PR #29 の追加実測監査。公式Cannon Parkの旧固定12開催日・1～8Rのみ。**
解析データは再取得した現source馬名簿版に条件づく、回顧的な正のGPS区間観測。**元の2026-10-14名簿まで12/12復元できていない**（全項目一致3/12、名簿版相違9/12）。実市場の競走前情報や個別票額は扱っていない。

## 問い：馬自身の過去履歴が将来の行動を予測するとは、何を予測することか？

同じ馬の過去GPSには、少なくとも二つの別の被説明変数がある：

1. **レース内相対タイム**：馬 i の初区間秒数 − 同レースでGPS観測のある他馬の初区間平均。観測された後続レースの相手を使って**事後的に**定義する値。行動の相対位置づけ・文脈依存性を検査するもので、事前の馬の絶対ペースや賭け率を意味しない。
2. **絶対初区間タイム**：馬 i が実測で示した初区間秒数そのもの。推定時に後続レースの他馬のGPSを一切使わない。未知の後続レースの共通効果（走路、出走集団、騎乗、当日馬場等）は直接予測していない。

どちらも**完全に同じ出走者名簿・未来の評価対象**を使用。相対評価と絶対評価で母数を都合よく変えない。元のmainで以前に固定したsource HORSES IDの新規documented Jockey/@Id、GPS first marker、公式距離、Class（追加感度）を踏襲し、各評価日より**厳密に古い日付**だけから過去馬履歴・他馬の同条件履歴を作る。

自馬履歴は元デザインの n/(n+2) 縮約を固定し、後続観測の馬IDと公表sourceの馬IDは匿名で内部照合するだけ。個別ID、名前、騎手番号、初区間秒数、個票予測をGitHubへ記録しない。

## 対象と計算

[匿名集計コード](../../scripts/keiba_rq_frozen_target_date_sensitivity.py)。後続の未来レースの日付を1日ずつ取り除くleave-one-**future meeting date**-out診断を実施する。毎回、**元の固定スコア済み予測の配列から評価日だけ削除**し、horse-equal weighted RMSEを再計算。除外後も元デザインの最低閾値 **20個体ID、20評価記録、6後続source開催日**を満たすか別途記録し、HOLDになる削除を黙って捨てない。

追加399回の **日付単位resampling** は観測された後続日を塊として再標本化し、自馬と他馬のペア予測値を保持。**これは信頼区間、集団p値、独立な399開催日の試験、年を跨ぐ予測検証ではない**。同じ回顧的データ内で符号がどの程度変わりやすいかの計算診断のみ。

## 解釈と限界

- 実GPS同一馬IDの**相対的な初期行動順位・差の予測情報が源データ内に存在すること**は、元の古い他馬履歴、同レース内過去GPS馬IDの入れ替え帰無299回、11回の日付削除でも相対的に安定した正の結果。
- ただしその相対測定値は **未来の他馬の観測値を引いた被説明変数**。真正の将来の絶対走行タイム、個体速度パラメータやレースの勝馬順位がよりよく予測できたとは別。今回の**同じ35頭44行の絶対初区間**では自馬の過去履歴に追加予測優位がなかった。
- 対象は「源のdocumented Jockey IDが過去と異なる」のみで、実際の騎手が変わったと確証できていない。GPS欠測・出走選択・trainer・馬場・距離・競走ペース共通効果は残る。
- 150m・250mのGPS first markerは相互に同じ生物学的形質であると確認されていない。プールしたICCと、同一marker/distanceでの個体予測誤差は分けて報告する。
- 本PRの**主source gate HOLD**は依然として正しい。meeting/race/GPS原SHAは12/12一致したが、GetHorsesForRace元名簿の統合SHAは9/12日に変更され、original 543候補対最新526候補になった。元10/14の確定集団を同一版で再生できたわけではない。

## 次の独立実証条件

真に必要なのは、source版と利用可能時刻が最初のオッズより前に証明できる **同じ公式HORSES IDのGPS履歴** と、将来別開催日での **同じmarker/distance/classの絶対初区間**、そして**同じ馬が実際に参加したレースの時系列投票市場**。後続レースの競争相手のGPSを予測入力へ入れず、horse-only vs context-only vs horse+context vs social-odds-only などを事前封印して比較するまでは、馬ABM/PDEから実オッズへの因果効果・臨界オッズの存在はすべてHOLD。

**科学的結論：** 競走系の個体の記憶は、集団に対する相対的行動の反復性としては実測された。しかし「個体履歴が本質的な絶対速度を高精度予測する」や「個体の速度が市場の情報階層を説明する」という主張にはこの実測は足りず、Class調整後の小さな絶対改善はサンプル不足・source改訂を含む追加検証が必要。
