# 競走馬の反復GPS個体差：レース内相関を保持した事後分布と統合ABM/PDE

**2026-10-26 / Draft PR #26 / 完全人工データでの計算検証。** 原mainのRacing Queensland実測結果や、JRAの実投票の新しい経験的発見ではない。実馬GPSや私的価格時系列をGitHubに再配布しない。

## なぜ「個体効果を独立にサンプリング」するだけでは足りないか

従来の実験実装は、同じ馬が繰り返し走った最初のGPS区間秒数から、同レースの**他馬平均**を引いて相対時間 y_ir を定義した。その上で各馬の縮約事後分散を**独立に**サンプリングし、馬ABM／非局所PDE／投票者ABMへ渡していた。

しかし、ある馬が速かったというレース内の相対値は他の馬が遅かったという相対値と機械的に関連する。同レースの共通平均を引いた残差を n 個の独立した観測とみなすと、その共有情報を二重に数えることになる。

今回 [レース内直交コントラストモデル](../../scripts/keiba_race_contrast_trait_posterior.py) を追加し、競走 r に n_r 頭のタイムが存在するとき

t_r = μ_r 1 + Z_r a + ε_r,
a ~ N(0, σ_a² I), ε_r ~ N(0, σ_e² I)

と定義。全馬の元の秒数からレース内平均だけを除く射影

P_r = I_r - 1 1' / n_r

を使用する。P_r の rank は n_r−1 なので、n_r 人分の独立データがあるかのように扱わない。

**分散成分 σ_a², σ_e² を固定した条件での厳密な Gaussian 事後**

V^(-1) = I/σ_a² + sum_r[ Z_r' P_r Z_r ]/σ_e²

m = V sum_r[ Z_r' P_r t_r ]/σ_e²

を解いて、各馬の事後平均 m と**全馬を同時に扱った共分散 V**を推定。σ_a², σ_e²自体はまだ実測で確実に推定していない。現行既定値はソース依存の粗いmethod-of-momentsを代用しており、他馬との差による y_ir の分散を本来の絶対秒数 ε_ir の分散とそのまま同一視する偏りがありうる。これは**固定分散の条件付きwhat-ifモデル**であって、元mainの race-fixed REMLと同一ではない。

### 「測定誤差の相関」と「個体効果の事後相関」は別

同一レースに n 頭、元の絶対時間残差 ε が独立・同分散なら、他馬平均との差 y の**測定誤差の相関**は理論上 −1/(n−1)。人工6頭では **−0.20**。これは生物学的な馬同士の負の相互作用の証拠ではない。

一方、相対時間だけではレース全体で共通な馬効果の原点は識別されないため、Gaussian priorで正則化した**事後馬効果の相関**は正になることもある。人工6頭・7競走では最大絶対事後相関 **0.92136**。これを「実馬の行動が同調した」証拠とは解釈しない。

## 同じ馬ABM・PDEと市場に確率分布を通す

[統合ensemble](../../scripts/keiba_trait_uncertainty_ensemble.py) は次の3つを明確に区別する。

1. independent_approximation：旧版、各馬のmethod-of-moments推定・独立事後draw。歴史的比較用で欠測相関を無視する。
2. race_contrast_marginal_independent：**新モデルの同じ個体効果事後平均 m、同じ馬別事後分散 diag(V)** のまま、相関成分のみをゼロにしてdraw。**共分散だけの反事実対照**。
3. race_contrast_covariance：同じ m と同じ diag(V) に加えて、Choleskyで**全馬のVの非対角要素を維持**してdraw。

それぞれ**同一の元レース履歴、同じ初期市場 q0、同じ馬ABMのGumbel/Brownian乱数、同じ仮想投票者の選択乱数**を使う。馬ABMと任意のPDEチェックは同一の非局所前方混雑カーネル。市場は fundamental / herding / informed に分け、後から届く公開情報が過去の市場に漏れないよう時刻で区切る。

重要な切り分け：

- (1) vs (3) は**事後平均の推定方法と共分散構造の両方**が違うので、差をすべて「相関の効果」と呼ばない。
- (2) vs (3) は**事後平均・個体別分散が同じ**なので、固定した人工Gaussian模型内で、非対角共分散の影響を比較できる。
- 個体効果のglobal common shiftは相対タイムだけから識別できない。馬priorをsoftmaxすると共通offsetはキャンセルされる。
- 投票市場の説明変数へ**競走中に起きた真のレース情報を発走前に逆流させることはしない**。市場に届くのは事前客観指標に基づいた仮想公開シグナルのみ。

## 人工デモの初期確認

[実装デモ](../../scripts/keiba_trait_uncertainty_demo.py)、固定seed 20261026、人工6頭・7競走、20個体効果draw×80馬物理MCから：

| 人工条件 | 馬の混雑を操作したときの仮想市場TV差（pp） |
|---|---:|
| 旧独立method-of-moments＋独立サンプリング | **0.16125** |
| 新race-contrast Gaussian＋全馬共分散サンプリング | **0.19625** |

人工6頭の新モデルの最大offdiag効果事後相関 0.92136。ただし**この2条件は平均値と分散の推定まで異なる**ので、これだけでは共分散の純粋な寄与と断定できない。真の相関影響は「同じrace-contrastのmとdiag(V)」で比較する(2) vs (3)に限定する。

同一人工デモの情報非公開対照では、馬側の混雑有無を変えても投票市場の最終差は**厳密に0**。市場価格の絶対10倍閾値をいっさいコードから推定したわけではない。

## ソース・単位・テスト

- 馬ID、GPS first marker、距離、Class、各行のracedate・受信時刻、**最初の公開市場価格より前にGPS履歴を取得済み**、客観情報源の権利確認等を要求。ローカルの真偽値だけで外部時刻やデータの真正性を証明したとはしない。
- 同一馬・同一sourceローカル日付で2レースの観測がある場合は入力を**fail-closedで拒否**。未来着順や後続オッズは予測入力に使わない。
- [共分散専用テスト](../../tests/test_keiba_race_contrast_trait_posterior.py)：全馬・全レース同名簿のGaussian閉形式、元レース共通時間の平行移動不変性、馬IDの一貫した置換不変性、測定ノイズ負相関と事後効果正相関の区別、source時計/使用権の拒否、人工seed再現性。
- [市場との統合テスト](../../tests/test_keiba_trait_uncertainty_ensemble.py)：確率質量、独立初期q0の分離、同じmとdiag(V)を持つ全共分散/対角のみの比較、事前未公開の情報遮断、完全に公表しなかった場合の市場一致、数値PDE。
- [固定された人工seed群の感度解析](../../scripts/keiba_race_contrast_seed_sensitivity.py) は複数乱数で人工比較を繰り返し、単一seedで方向の決定を過信しないためのもの。異なるseedを独立した現実レースと数えない。

**研究上の現在地：同じ馬・同じ過去反復GPSの共分散を条件付きガウス事後へ正しく反映して一つの馬ABM/PDE・投票者市場へ渡せる方法論を実装した。実馬の個体性と社会的市場の因果的接続、真の臨界オッズ、正の馬券期待値は未実証。**


## 8 seed で共分散だけを切り替えた人工感度分析

[実行済みGitHub Actions・8シードの機械可読artifact](https://github.com/zuizui0223/keiba/actions/runs/40282538366) を保存。人工6頭・7レース、**各シード12 latent trait draws × 60 physical MC draws**。同一Gaussian race-contrast推定の posterior mean と marginal variance を完全固定し、(2)の対角のみ vs (3)の全共分散を比較する。両者の古い元market q0・物理シグナルと投票者乱数も共通。

| 比較 | 8つの乱数シードの結果 |
|---|---:|
| 全相関をゼロにした対照での「馬混雑による市場変化」の平均TV | **0.203385pp** |
| 全馬事後共分散を維持したモデルでの平均TV | **0.232813pp** |
| 全共分散−対角のみの平均差 | **+0.029427pp** |
| シード別最小差／最大差 | **−0.058333 / +0.097917pp** |
| full covarianceで市場差が大きかったシード | **6/8** |
| full covarianceで市場差が小さかったシード | **2/8** |

**反証的に重要なこと:** 1つの固定seedで市場効果が増加して見えても、それは共分散を反映すれば必ず増加するという証拠ではない。乱数の選び方次第で符号が逆転する。8シードは独立観測レースではなく、標本サイズ・不確実性の大きさ・物理ABM係数も全て人工固定である。したがってp値・95%母集団区間・JRAの相転移・馬券収益は主張しない。

最後に**二つの「相関」**を明確に分ける。原のレース内GPS相対時間に生じる残差の負相関（6頭なら−0.20）と、共通の観測不能オフセットを正規priorで制約した馬個体効果の事後相関（toyの最大約+0.92）は統計的に異なる量。競走馬の真の協調・同調・相互作用の実証ではない。
