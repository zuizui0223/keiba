# 競馬市場の非単調性は別競走にも再現するか：京都8Rの元3時点と天皇賞の部分時系列

**2026-10-31に行った原資料固定・過去アーカイブ解析（Draft）。** 観測結果は「連続価格変化でも非単調な変化は起こる」ことを確認するための方法論上の実例。新規の前向き収集、賭け収益、実馬GPS、実際の投票者の追随効果ではない。

## 2競走で異なる証拠水準を明確にする

- **京都2026-10-12 8R**：既存の公開元資料をGit blob SHAで固定した **11頭全件・12:21、13:26、13:44の3時点**、計55馬ペア。元オッズソース／掲載更新分／取得時刻を確認する [既存のsource-gated reader](../../scripts/odds_r8_real_three_time_market.py) を直接再利用。11頭とも元時刻が整合する。ただし同一publisherの表示更新分であって原JRA投票トランザクション時刻ではない。後から集めた3点の**事後再解析**。
- **天皇賞（秋）2026-10-31前日報告**：[PR38](https://github.com/zuizui0223/keiba/pull/38) 固定の可変ブログ記事。05時点で最初は4頭・以後5頭のみ。「06:08,08:09,12:07,13:08,15:08」は記者の記載値であって独立した元受信時刻の証拠ではない。**10馬ペア・1競走**。未知12～13馬の価格を創作しない。

[PR39](https://github.com/zuizui0223/keiba/pull/39) の3つの表示丸め仮定を変えずに、京都8Rへ再適用：
  - 四捨五入を仮定：[表示値−0.05、表示値+0.05]
  - 切り捨てを仮定：[表示値、表示値+0.10]
  - **両仮定を包む広い区間**：[表示値−0.05、表示値+0.10]

本物の表示丸め規則を知っていると装わない。元資料の数値が1桁表示であることの感度分析。

## 主要実測結果：別競走でも方向転換が必要

| 独立した元競走 | 比較ペア（同一レース内で従属） | 四捨五入仮定の必須方向転換 | 切り捨て仮定の必須方向転換 | 保守的に広げた誤差範囲で必須方向転換 |
| --- | ---: | ---: | ---: | ---: |
| 京都8R（11頭3時点） | 55 | 3 | 3 | **2** |
| 天皇賞（選ばれた5頭5報告時点） | 10 | 8 | 8 | **6** |

京都8Rの保守的な2組は **③–⑩、③–⑪**。元京都8R表示オッズ：
- ③対⑩の3時点は **7.7/18.3 → 6.7/16.8 → 6.3/12.8**。log相対オッズは **−0.86568 → −0.91927 → −0.70890**（下降→上昇）。
- ③対⑪の3時点は **7.7/5.3 → 6.7/4.9 → 6.3/3.9**。log相対オッズは **+0.37351 → +0.31287 → +0.47957**（下降→上昇）。
- ⑤対⑨は四捨五入／切り捨てそれぞれで必須方向転換の3番目だが、**さらに広い合併区間を使うと必須の方向転換として残らない**。

**解釈**：異なる日・競走で、単調に一方向へしか変わらない相対市場評価モデルは少なくとも一部の観測値と矛盾する。ただし「京都では2/55、天皇賞は6/10だから差がある」という比較は禁止。天皇賞は編集者が選んだ有力5頭だけを測定、京都は全11頭、観測長も3と5、時計の証拠水準も異なる。**独立した元競走は2件**であり、この数から普遍性のp値、馬券のエッジ、集団情報の機構は分からない。

## 方向転換が見えても「離散的な大口投票・相転移」は必要ない

今回新しく加えた数学的比較は **連続価格だけで再現するには最低どの程度の変化速度が必要か**を定量化する。ただし速度は source に記された掲載更新時刻を使用した条件付きの量で、真正な個々の投票速度ではない。

各馬ペアの log相対価格 z の各時点について、表示丸め条件で [L_i,U_i] とその掲載更新時刻 t_i がある。**常に |dz/dt| ≤ s を満たす連続（Lipschitz）過程**がこの点を通れるための最小値は

\[
s_{\min}=\max_{i<j}\frac{
 \max(0,L_i-U_j,L_j-U_i)}{t_j-t_i}.
\]

これは単なる必要条件ではなく**必要十分条件**。構成的な証人 \(z(t_i)=\max_j[L_j-s_{\min}|t_i-t_j|]\) により、すべての時間点で元の許容区間へ入り、連続で、速度上限を満たせる。ソフトウェアは全ペアでこの数理的証人を検証し、数値誤差分だけ上限へ+1e-10/hの余裕を加える。

**京都8Rで全55組の相対価格軌道を個別に連続過程として表現する場合**の最も大きな最低必要変化速度は以下：

| 表示誤差の仮定 | 最も厳しいペア | 55ペア中の最大の最小速度（log相対価格／掲載時間） |
| --- | --- | ---: |
| 四捨五入 | ⑥–⑧ | 2.066972/h |
| 切り捨て | ⑥–⑧ | 2.058077/h |
| **さらに広い誤差区間** | **⑥–⑧** | **2.031997/h** |

このペアの速さを「市場が臨界点を越えた」と呼んではならない。0.10/hはPR19で**全頭の正規化市場指数**に与えた別の**仮定の投票者反応閾値**であり、このペアのlog相対価格速度と尺度が一致しない。**数値の大小を直接比較して因果的結論を出さない**。

さらに、本物の11頭全員の3つの表示価格に対し、各馬のlogオッズ値を同時に五次smoothstepでつなげれば、**全11頭のオッズが連続かつC²級**で動き、毎時刻の相対市場指数も正で合計1という**一つの整合的な共同過程**を構築できる。これは京都8Rの元3点すべてと一致し、**突発的なジャンプ、外部ニュース、追随投票の自己強化が数理的に必須ではない**ことの反証となる。ただし、この曲線は事後の構成例であり、事前予測で良い・実際の市場がC²だったという証明ではない。

## 同じ実京都8RのPR36次価格予測へ直接接続

このPRは価格の曲率だけを別系統で検査するのではなく、既に存在する [PR #36](https://github.com/zuizui0223/keiba/pull/36) の**同じ12:21・13:26・13:44全11馬source**を使った7候補の価格指数予測スコアも**コードで再実行・照合**する。

元のPR36は12:21と13:26の全馬単勝＋別口のワイド源泉確認だけで候補を作り、コードの実行順序では13:44の元SHA固定次価格を後で開く。**しかし2026-10-12のq2はこのコードが実装された10/31より前から既知なので、厳密な真正前向き予測ではない**。

| 同じ13:44の1つの実市場指数に対する候補 | TV誤差（percentage points、小さいほど近い） |
| --- | ---: |
| 13:26の市場を据え置く | 9.656363 |
| 12:21→13:26の相対log価格モメンタムを延長 | **8.180965** |
| 連続ゲインを掛ける | 8.657105 |
| 仮定0.10/hのハード価格ゲート | **8.180965** |
| PR19の無情報投票者ABM固定（人工30seed平均） | 9.978719 |
| 同じく連続feedback | 10.395475 |
| 同じくハードfeedback | 10.464642 |

元の7候補・人工seed・価格パラメータはすべて**元のまま**。今回のsource再読により、同じ13:26→13:44の全11馬価格が**7ペアの順位逆転**とTV**9.656363pp**を示し、これが元PR36の持続モデルの誤差と数値的に一致することを照合する。

重要：今回の**3時点での方向転換が必須な2ペア**と、**13:26→13:44の2時点だけで順位逆転した7ペア**は違う指標。前者は「単調モデルが観測点を通れるか」、後者は「時点間で馬の価格順序が変わったか」であり同じ件数にしてはいけない。価格予測の上位候補が今回最も誤差の小さいことは、非単調性から自己強化や投票者の急変機構を見つけたという意味ではない。**数理的な持続・モメンタムで当てはまる事例**と、**実機構の非同定性**を同一実レースで示したことが、この統合検証の位置づけ。

## 実レースの因果モデルへ接続する条件

これまでの[PR37](https://github.com/zuizui0223/keiba/pull/37)は馬ABM→非局所PDE診断→情報階層型投票者ABMを同じWIN q0/q1と将来q2に結びつける**11候補**。本研究の分析はこの候補・パラメータ・sealed予測を**変更しない**。

新しく実証できたのは、①部分記事だけの現象ではなく、**別競走のsource-locked全頭3点でも非単調な相対価格が存在する**という事実。現実の投票者に何が情報を与えたか、情報なしの連続モデルで将来予測できるか、馬の実GPSから市場価格をどれくらい説明できるかは依然未同定。

未来の真正な比較では、認可された元WIN q0/q1、別の実q2、元資料更新時計とローカル受信証拠、PR30/PR37の**2つのpretargetサーバーSHA登録**、固定された11モデルのTV/KL採点を用いる。ニュース／投票量／馬の行動情報がない場合は、それらの因果機構はHOLDとする。京都8R・天皇賞の**古い事後データを新規前向き試験へ繰り上げない**。
