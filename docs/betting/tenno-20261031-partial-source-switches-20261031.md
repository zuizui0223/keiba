# 天皇賞（秋）2026：同じ2強の首位交代と、部分観測の誤解を避ける順位監査

**2026-10-31に公開情報から追加した探索的な実数値検証。公式JRAリアルタイム元受信・前向きSHA登録とは別のクラス。実際の群衆情報の相転移・因果的な大口投票効果・馬の勝率校正を主張しない。**

## 重要な新規観測

[Race Postmanの更新記事](https://race-postman.hateblo.jp/entry/2026/10/31/061338)には、11月1日の天皇賞（秋）について、**10月31日06:08・08:09・12:07・13:08・15:08**のJRA取得として著者が記した上位4〜5頭の単勝表示オッズがある。ただし記事は同日15:09頃に追記が完了した後から通して読める形式で、**各時点のソース原本の取得成功を第三者が時刻認証した資料ではない**。

この記録を親 [PR #33](https://github.com/zuizui0223/keiba/pull/33) の公開記事**17:00全17頭**、親 [PR #35](https://github.com/zuizui0223/keiba/pull/35) の**17:42記事掲載全17頭**とつないで、全部で7つの「**媒体に記された時刻別数値**」を解析した。元JRAからの本物の7時点原本を取得したことにはならない。

**⑦→①→⑦の表示人気の首位逆転は2回**（08:09→12:07、13:08→15:08）。⑪シェイクユアハートと⑰ダノンデサイルも**12:07→13:08に1回**表示順位を逆転した。記事内で直接比較できる4〜5頭の部分行列について、6区間の厳格な逆転は合計**3ペア・区間**。最後の17:00→17:42だけ全17頭の136比較が可能で、逆転は0。よって1競走の**6区間＝独立6競走ではない**。

## 知っておくべきもう一つの検算：小数1桁の丸め

**表示オッズの差が0.1倍の場合、「厳密な内部順位の差」を過大評価してはいけない。** 裏の真の価格が小数第一位に丸められていると仮定し、馬ごとのオッズの範囲を表示価格 ±0.05倍として、一方が必ず高いかどうかを数理的に検算した。

各時点の2頭のlog odds比 log(o1/o7) の範囲を

    lower = log((o1 - 0.05)/(o7 + 0.05))
    upper = log((o1 + 0.05)/(o7 - 0.05))

で保守的に求める。両端が厳密に正なら⑦の相対人気が上、両端が厳密に負なら①が上、0を含む／接する場合は**丸め境界があるため不確実**とする。

- **08:09**：⑦2.4倍対①2.6倍。⑦優位が丸め幅を入れても明確。
- **12:07**：①2.5倍対⑦2.9倍。①優位が丸め幅を入れても明確。
- 従って**08:09→12:07の1回の逆転は、小数1桁の丸めを保守的に考慮しても厳格に残る**。
- 一方**13:08**は①2.7、⑦2.8、**15:08**は①2.6、⑦2.5。表示値としては逆転したが、差0.1倍のため、内部の真の価格がまさに丸め境界付近で同程度であった可能性を否定できない。**2回の「表示逆転」を2回の「真の市場の急変」と言い換えてはいけない**。

丸めの仮定自体が実際のJRA内部単勝票比率の精度・丸め処理を証明するものではない。これも**感度解析**である。

## 技術的な保全：部分観測は部分観測として扱う

追加した source-declared script keiba_tenno_partial_article_timepath.py は、ブログの上位4→5→5→5→5頭の数値を「**観測できた頭数**」として固定し、記事URL・源泉種別・著者記載時刻・数値すべてをUTF-8 canonical JSON SHA256 **6ac80f588f4ade9007a4db1150dc628b421195ff20db5854c2085fbbff2336f9** へ結合する。これは**当該値をコード内で改変しないためのチェックサム**であり、元のsourceが本当にその時刻に取得されたという外部監査ではない。

- 一部の時間帯で馬⑰は掲載がない。**未掲載を0倍、失格、人気が低い、欠測値補完としない**。
- 共通4頭・5頭だけを対応づけて順位交差を数える。**17頭全体のM0支持率の分母を4〜5頭から勝手に推測しない**。順位比較は馬同士のオッズ差のみなので、全馬指数の偽補完を避けられる。
- **17:00と17:42だけ**親PR33/35の原17頭SHAを再読して全136ペアの価格順位監査／17頭市場指数TVを出す。ここでのTVは約**0.3320355 pp**、逆転0。17:42記事と18:00記事が同じ17頭だった従来の反証も維持。
- 欠測と時刻の表示を全モデルへの単勝q0/q1入力として使える条件を混同しない。**今回の7時点公開資料はPR30/37の真正前向き元ソース・次q2として不適格**。

## 投票者ABMと大口投票の仮説への関係

[SPREADの記事](https://spread-sports.jp/archives/402071)は、14:51頃の⑦単勝190万円などの**推定**大口投票イベントも掲載している。これは⑦が13:08の2番人気から15:08に1番人気になった報道値の間に位置する、という**今後の仮説候補**になり得る。

しかし同記事は投票時間・金額を「目安」としており、JRA生投票ID・正確な受注時刻・対応オッズ更新・全投票量を示す真正一次資料ではない。**特定の大口投票が順位逆転を引き起こした、投票者の自己強化や情報閾値が存在する、と結論しない**。また実投票行動は馬の実GPSや同一馬反復行動を測ったものではない。

**新しい肯定結果**は限界つきで「同一の2頭が記事に報告された数値時系列の中で一度離反・再接近し、その順位が繰り返し入れ替わる」「単勝の完全情報は終盤の2表のみで、部分観測の欠測を認めると検証できる範囲が狭まる」という記述。より一般的な集団情報の機構を問うには、元PR37の合法な全頭WIN q0/q1、別の未来q2、2つの外部SHA時刻、独立した馬履歴が必要。
