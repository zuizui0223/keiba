# 2026-10-12 京都の分析範囲

目的は、ユーザーが当日の京都競馬について京都実績と中間オッズを比較し、買い目の条件と収支を判断できること。既存リポはREADMEのみだったため、学習済み予測モデルを実行したという主張はしない。

## 入力・計算・出力

1. `data/2026-10-12/kyoto_06.json`〜`kyoto_12.json`：全頭の出馬情報、芝/ダートを分離した京都通算、確認できた同距離成績、中間オッズ、更新/取得時刻、根拠URL、会話での定性評価を保存。
2. `scripts/analyze.py`：入力整合性と時刻を検証し、京都の記述的好走率、券ごとの損益分岐的中率、単独的中時の全体収支、同一軸の券の同時的中可能性を計算。
3. `reports/2026-10-12/`：固定した分析時刻で再現できるMarkdownとJSON、入力SHA-256を出力。

## 判断の境界

- 過去の馬券内率は今日の的中確率ではない。比較対象の距離、クラス、休養をnotesに残す。
- `null`は履歴未確認/未出走の注記付き欠測。確認済み0戦の `[0,0,0,0]`と区別する。
- 印と優先買い目は定性判断。プログラムが学習して出した順位ではない。恣意的な重み付きスコアや未検証の期待値を作らない。
- 同着なしの通常の3着以内を列挙する。列挙した着順組合せを等確率とは仮定しない。
- 100円×点数は説明用予算。実際の購入、投票、口座接続は行わない。
- 発走2分前を分析上の新規候補停止時刻とする。これは販売締切時刻を保証するものではない。
- オッズの古さは分析時刻から計算し、15分を超えたら再確認表示を付ける。この15分は運用上の目安で、的中確率の境界ではない。
- 中間オッズの下限を固定した収支試算であり、最終払戻を保証しない。取消・返還・同着の特殊払戻は対象外。
