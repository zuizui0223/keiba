# 2026年菊花賞：結果を見る前のモデル分離度・検出力監査

**2026-10-24 発走前。これは予測値の結果非依存な数理監査であって、実際の勝馬・3着内・馬券利益を採点した結果ではない。**

## 事前提出記録と再現

2026-10-25京都11R菊花賞（18頭、15:40 JST）の予測ファイルは、2026-10-24 17:05:37 JSTに作成され、SHA256 **9ef880b44decf3b38c4ea01ece9570bd4c6c61d636db26f05af8181fe41fe857** として [GitHub PR #10の最初の事前コミット](https://github.com/zuizui0223/keiba/pull/10#issuecomment-6381798252) に提出された。GitHubサーバのcreated_at=updated_at=2026-10-24T08:07:18Z。元の18頭×2時点の非公開公開市場ソース保存ファイルのSHA256は **407c9c804cb4cc029fed1a2ebaec9e9a9336d6e8b2b8b7826c174637536668bd**。

既存の予測内容は変えていない。追加した [scripts/odds_preoutcome_discriminability.py](../scripts/odds_preoutcome_discriminability.py) は、この封印ファイルから*結果を読み込まずに* M0とM1/M2の確率分布の差のみを計算する。全18頭の勝率質量1、各馬Top3質量合計3、全816組の三連複確率質量1、およびTop3が三連複共同分布から正しく復元できることを検査する。

## 予測ファイル同士はどの程度違っていたか

| 発走前に分かるモデル間の比較 | M1（経路β=0.25）対M0 | M2（早期10倍以上だけβ=0.25）対M0 |

**重要：KLはどちらかの分布が真実だと仮定した場合の予測対数損失の期待差**。M0が真実だという経験的な証明も、候補が真実だという証明もない。Top3 Brierの期待差も同様で、M0が真実なら平均的にはM1より約0.00003247だけ低い損失を持つ、という数学的恒等式である。どちらのモデルが現実に近いかはこの時点では未知。

### 非自明な点

**18頭中11頭の勝利ならM1の予測Log lossが小さくなるが、その11頭のM0基準勝率の合計は約17.6%しかない。** 個別馬の数だけで「11/18だから改善する可能性が高い」と見てしまうのは誤り。上位の市場支持が多く集まる馬の予測差と合わせて判断しなければならない。

加えて、M0とM1の全馬勝率分布の距離はわずか0.945ポイント、KLも0.000444 natsである。**今回の1レースの結果でオッズ経路の普遍的な追加予測情報を確認するには、事前からモデル同士の分離度が非常に小さい**。1着馬がどれになっても主要な勝馬Log loss差は−0.1048〜+0.0399程度。個別の良し悪しだけでは一般化不可能。

三連複全816組の分布の距離は単勝より少し大きいが、それでも観測は1レースであり、これを独立816サンプルとする検定は成立しない。

## 何を今後の評価で使うか

[事前提出時の主要対比](odds-first-precommitted-kikka20261025.md)はあくまで **勝馬Log loss M1−M0**。副次指標はTop3 Brier M1−M0。M2の早期10倍閾値は探索として評価し、結果を見て最適な閾値に差し替えない。この「分離度」監査は事前登録された第三の的中指標ではなく、モデルの予測値にどれほどの違いが元々あったかを、レース結果が出る前に記録するためのもの。

結果確定後は、JRA公式1〜3着、独立確認時刻、固定された予測封印とGitHubコメントを再照合する。次の開催日でも同じモデル係数と評価基準を再使用できる、独立したレースが増えるまでは普遍的な閾値・情報伝播・馬券期待利益を主張しない。

## 元市場オッズと封印予測の独立再計算（結果前）

[元の非公開市場JSONから確率を再現するコード](../scripts/odds_private_source_replay_audit.py) と、改ざん時にHOLDを返す[対応テスト](../tests/test_odds_private_source_replay_audit.py)を追加した。

実際の2026/10/25菊花賞の保存した元市場JSONは、競馬ラボが一般公開している[10/23 22:57の単勝表示](https://keibalab.jp/db/race/202610250811/odds.html)の**18頭すべて**、および[10/24 09:23の単勝表示](https://www.keibalab.jp/db/race/202610250811/odds.html?kind=tan)の**18頭すべて**と、馬番ごとに一致した。これを経由したファイルの生bytes SHA256は前記の封印に記録したものと一致した。公開ページの表示時刻が本当の最終投票受付・プール資金量を証明するわけではない。

さらに元の18頭×2時点の逆単勝相対指数から、M0/M1/M2の3種類のPL上位3頭共同順位モデルを**予測結果や公式着順を見ずに独立に再計算**した。各モデルごとに単勝18、3着内18、三連複816の全確率が元の封印ファイルと**数値誤差0**で一致した。3モデル全体では2,556の個別確率が照合されている（18+18+816=852/モデル）。これは数理モデルの実行再現性であって、現実の勝馬・三連複の的中確率が校正されている証拠ではない。

SHAの外部提出記録とソース市場の一致、数理的な再現性はそれぞれ別の検査。この再現コードはユーザーの非公開JSONをローカルでだけ読み、オッズや馬別予測値を公開GitHubへアップロードしない。集計だけの検査結果を出力する。
