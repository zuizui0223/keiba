# オッズの経路依存・情報階層・非同調更新

**2026-10-23。秋華賞1レースの保存済み市場価格を使った記述監査と、完全に合成した投票者ABM。勝率の閾値・追随効果の因果性・正の馬券期待値を実証していない。**

このブランチは [秋華賞のオッズ時系列を保存したDraft PR #5](https://github.com/zuizui0223/keiba/pull/5) から分岐している。生態学研究、v3.1の本番凍結ルールや20レース正式検証、別系統の実馬ABMを変更しない。

## 中心問い

**初期の市場評価が後続投票のアンカーになり、新しい情報が馬ごと・券種ごと・時間帯ごとに異なる速さで反映されるとき、どんな条件で最終結果の予測に追加情報が生じるか？**

重要なのは二つの予測先を区別すること。

1. **次のオッズの変化を予測できるか**。初期の相対人気、集団の偏り、過去の変化パターンを使用する。
2. **実際の勝馬と3着以内をより良く予測できるか**。同じ時刻に利用可能な最新オッズのみのモデルより、価格がそこへ到達した経路で、将来の独立したレースのLog lossとBrierが改善するかを見る。

第一の予測が成功しても第二の予測性能や賭けの正の期待収益は保証しない。

## H1〜H4

- **H1 初期市場の経路依存**：近走・馬場・騎手・天気などに関する投票者の期待が当初の市場を形成し、その可視化された人気が後続投票を誘導する可能性。オッズは運営者が能力から直接設定する値ではなく、投票から作られる内生変数。
- **H2 変化の閾値・状態転換**：人気集中度、時間帯、初期オッズ帯などの条件で、後続変動と結果予測への追加寄与が非線形に変わる可能性。既存監視の「オッズ変化絶対値20%以上」は*運用上の異常検出値*であって、予測が当たり始めると発見された閾値ではない。
- **H3 馬×券種の非同調性**：単勝支持と、他の馬とのワイド共同入着イベントへの相対支持は別々の情報を持つ可能性。券種間の配信・発売時刻が一致していない点とイベントの相違を考慮する。
- **H4 時間的な情報階層**：初期の人気固定、日中の小さい更新、翌朝の再配分、終盤の情報更新など異なる時間スケール。わずか4時点のデータから特定の投票者の学習時刻や追随機構の因果効果を同定できない。

## 1. 秋華賞で確認した実データ

使用データは土曜14:37と15:37のYahoo/SportsNavi中間オッズ（取得開始時刻）、日曜11:42と12:18のJRA単勝オッズ（発表時刻）の**4セット×17頭**。最初の取得点は*発売開始直後のオープニングオッズではない*。土曜と日曜で提供元も違う。単勝オッズから計算する相対指標は

\[
q_{it}=\frac{1/o_{it}}{\sum_j1/o_{jt}},
\]

であり、実際の勝率や厳密な生投票額ではない。

| 収集済み時点 | 8番に対する相対市場重み | 市場の実効馬数 |
|---|---:|---:|
| 10月17日14:37 Yahoo取得 | 63.58% | 4.70 |
| 10月17日15:37 Yahoo取得 | 63.76% | 4.65 |
| 10月18日11:42 JRA公表 | 56.56% | 5.73 |
| 10月18日12:18 JRA公表 | 56.28% | 5.76 |

実効馬数はShannonエントロピーの指数であり、レース参加頭数ではない。8番が1番人気を保ったまま相対重みが低下した。初期の人気上位5頭のメンバーもこの観測窓を通じて維持された。

相対市場配分の再配分量を

\[
\mathrm{TV}(t_0,t_1)=\tfrac12\sum_i |q_{it_1}-q_{it_0}|
\]

と定義すると、

| 隣接時点 | 再配分量 (百分点) | 単勝オッズ20%以上変動した馬 | 上位5頭の構成 |
|---|---:|---:|---|
| 土曜14:37→15:37 | 0.556 | 0/17 | 不変 |
| 土曜15:37→日曜11:42 | **7.582** | **6/17** | 不変 |
| 日曜11:42→12:18 | 0.570 | 0/17 | 不変 |

異なる更新周期で価格が動くが、**中間のギャップを観測していない**ため本当の変化点はこの表から分からない。特に翌朝へのギャップは時間経過とソース変更が交絡する。

### 136組のワイド：8–14と3–8の順序逆転

各ワイド・プールから全136組の下限中間価格を比較した。単勝14番は土曜15:37の**43.6倍 → 日曜12:18の35.4倍（−18.8%）**。それに対しワイド8–14は**4.4倍 → 7.8倍（+77.3%）**。ワイド3–8は6.4倍 → 6.2倍で、両ワイドの*人気順は逆転*した。単勝14番の人気増と「8–14の共同3着内」という券の人気減は両立し得る。

ただし券種間で元の更新時刻が証明されていないこと、単勝とワイドは的中イベントも総投票も違うことから、「馬の情報が何分遅れて伝播した」という因果解釈は**HOLD**。

再現コードは、ワイド下限の逆数を全136組で正規化した**相対価格インデックス**と、同じ時点の単勝を用いるPlackett–Luce（PL）モデルが示す両馬Top3の共同確率を比較する。136組のワイドは同時的中し得るため、逆数正規化は**確率ではない**。共同Top3確率はPLの仮定に依存し、これも経験的に校正された独立の確率ではない。この差は市場間の探索指標で、収益確定や裁定機会の証明ではない。

## 2. 初期人気と後続情報の理論モデル

レースrの初期支持は、投票者の期待を通して形成される。

\[
q_{i0}\propto \exp[f(X_{i0})+u_{i0}]
\]

後続の投票者が、人気追随タイプと新しい情報に反応するタイプを混合する場合、

\[
b_{it}=(1-\alpha_t)
\frac{q_{it}^{\gamma}}{\sum_jq_{jt}^{\gamma}}
+\alpha_t\frac{\exp(\theta_i+\eta_{it})}
{\sum_j\exp(\theta_j+\eta_{jt})}
\]

さらに既存プールに累積投票を追加すると、

\[
q_{i,t+1}=\frac{B_t q_{it}+\Delta B_t b_{it}}
{B_t+\Delta B_t}.
\]

指数gammaは追随の強さ、alphaは新情報の重み、thetaは観測不能な状態を表す。このモデルは**実際のJRAオッズ計算式を再現したものではない**。累積投票という基本構造の仮説を表現するための理想化した投票者ABMである。

シミュレーションは、最初の市場相対支持を人工的な初期プールにして、(a)全員が人気追随、(b)全員が人工シグナルへ反応、(c)初期は追随が多く後半はシグナル反応が増える、という3条件で比較する。実際の投票者タイプの割合は*推定していない*。新情報は初期人気順位に対して恣意的に与えるもので、現実の後続オッズ・馬場・結果から推定していない。

仮説と数理形態の前例：
- [Mori & Sugawara, Physica A (2025), DOI:10.1016/j.physa.2025.130982](https://doi.org/10.1016/j.physa.2025.130982) — JRA投票市場の追随と情報型投票者を用いた時間依存OUモデル。
- [Hanyu et al., UTMD-149, 2026-08-21](https://www.mdc.e.u-tokyo.ac.jp/en/news-en/9727/) — JRAの中間オッズ経路と直前オッズ変化に関する実証・情報モデルの改訂論文。

単なる「追随者と情報型がいる」という主張自体の新規性は弱い。将来研究で差別化するのは**券種横断の非同調性、初期集中度と時間帯に依存する状態転移、結果への独立した予測寄与**である。

## 3. 検証上のHOLDと将来の識別設計

本保存データでは17馬×4時点だが**独立したレースは1件**。17頭を17回の独立な成績観測として閾値の検定に使うのは疑似反復であり、絶対に行わない。

- 初期人気が後続価格を**因果的に**動かしたか：追随、外部情報、累積プール、価格丸めの交絡が残るためHOLD。
- ある具体的な単勝オッズや20%超変化で勝率/複勝率の予測性能が急に良くなるか：レース間の時系列評価が必要なのでHOLD。
- 複数券種での価格シグナルの実際の更新ラグ：提供元時計が非同期なのでHOLD。
- JRA馬券購入や確定配当を計算できるか：この分析は購入行為・実馬券ROIを一切扱わない。

将来の主解析は、複数開催日から**レース単位で完全な馬番・単勝・ワイド・競走前の環境・過去走歴**を同一時点の来歴付きで収集すること。最新時点だけの基準モデルと、初期オッズ＋その後の時系列＋券種間の残差を使うモデルを、全く新しいレース期間で比較する。Smooth splineと事前登録した区分閾値モデルの差もレース単位で確認する。過去の勝馬で閾値を最適化したままそのレースの性能を報告してはいけない。

情報伝播の因果推定には、結果に影響する新しいニュース・場況更新の発表時刻や、匿名化された投注フローなど独立の変動を必要とする。オッズ単独から模倣効果の強さを推定することは原則として難しい。

## 4. 将来の実データ用：閾値モデルを訓練期間と将来期間で分離する

[時系列閾値評価の実装](../scripts/odds_threshold_forward_eval.py)を独立に追加した。現状の秋華賞1レースでは結果を返す代わりに **HOLD** とする。ソースが増えた場合だけ比較する。

最低必要な将来データ形式（JSON）：schema = WIN_ODDS_PATH_PANEL_WITH_VERIFIED_PUBLICATION_TIMES_V1、provenance = synthetic または rights_audited_source、races 配列。各レースには race_id、post_jst、early_win / latest_win（馬番→オッズの完全な表、market=JRA_win、provider_timestamp_verified=true、provider_published_at_jst）、公式3着内順と終了後に確認できた official_top3_verified_at_jst を持たせる。早期・後期の市場時計はレース発走より10分以上前、結果検証時刻は発走後とする。これは厳格な時系列データ試験用の契約であって、今のPR #5の異なる掲載更新時刻を恣意的に同時刻へ合わせることはしない。rights_audited_source という入力表示は*利用許諾の代用品ではない*。

モデルはレース単位の対数尤度とTop3 Brierを記録し、必ず過去開催日だけでパラメータを選び、その後の開催日の結果を初めて評価する。早期オッズ5・10・20・50倍という固定区分と、タイムパス係数ベータ−1・−0.5・0・0.5・1から候補を選ぶ。比較対象は「最新オッズだけ」、滑らかな時系列変化、初期オッズ帯でゲートした時系列変化。混合比と閾値を評価対象の未来結果で再調整してはいけない。

必要独立レース数60、異なる開催日8、訓練35以上、将来12以上は**ソフトウェアの最低データガードであり統計的検出力の保証ではない**。これを満たさなくても誤差や閾値を数値的に報告せずHOLDを返す。より厳密な信頼区間・多重比較・モデル選択の扱いは、多数の新しいレースで事前登録した後に評価する。

合成データを自動生成して未来だけで評価する方法は以下。

    python -m unittest discover -s tests -p 'test_odds_threshold_forward_eval.py' -v
    python scripts/odds_threshold_forward_eval.py --demo-synthetic --output tmp/odds-threshold-future-demo.json

合成データ内の「真の閾値」は生成器が恣意的に設定したもので、現実の馬のオッズ閾値があるという実証にはならない。

## 6. 追随なしでも価格に初期状態が残る：累積投票の数学的帰無モデル

追加実装：[scripts/odds_market_accounting_null.py](../scripts/odds_market_accounting_null.py)。

投票を集計するだけの理想化した市場において、初期の支持シェア q0、後期 q1、新しく入った投票の支持シェア b、*後期の累積プールに占める新規票の割合* lambda とすると、

\[
q_{1,i}=(1-\lambda)q_{0,i}+\lambda b_i,\qquad b_i\geq 0,\quad\sum_i b_i=1.
\]

同じレース・同じ馬の構成で、q0 と q1 が完全に分かる場合でも、lambda と b は一意に決まらない。具体的には

\[
\lambda_{\min}=\max_i\left(0,1-\frac{q_{1,i}}{q_{0,i}}\right)
\]

を満たす任意の lambda について、b=(q1-(1-lambda)q0)/lambda が非負に取れる。このため、**二時点のシェアだけから実際に新しく入った投票額や追随行動を推定することは原理的にできない**。

今回の保存単勝オッズの逆数をレース内で正規化した q を、あくまで仮想的に真の投票シェアに等しいと仮定すると：

| 2時点の比較 | qの再配分 (TV) | 条件付き lambda_min | 条件付き 新規/以前プール比の下限 |
| --- | ---: | ---: | ---: |
| 土曜14:37→15:37 | 0.556ポイント | 5.63% | 5.97% |
| 土曜15:37→日曜11:42 | 7.582ポイント | 17.20% | 20.78% |
| 日曜11:42→12:18 | 0.570ポイント | 2.75% | 2.83% |

**これらはJRAの本当の投票額・売上の下限ではない。** qは実際の投票シェアではなく、掲載単勝オッズを正規化した価格由来の代理指標にすぎない。JRAの単勝は総投票額と券種別の設定払戻率80%で概算払戻倍率が決まり、表示丸め・配信時刻・返還等も存在する。[JRA公式の計算式](https://own.jra.jp/faq/pop03/1_17.html)を参照。土曜→日曜の比較では配信元も異なる。仮想的な票の組合せは複数あり、実際の行動は特定できない。

### 追随なしの負の対照実験（300合成経路）

初期17頭の保存支持分布だけ使い、仮想的な累積10,000票に対し、あらゆる人気を無視して全17頭から均等に1,600票を追加する。別に、現在の人気の1.25乗に応じて追加票を入れる人工追随モデルを比較した。両者の初期状態と新規票数は同じ。

| 合成機構 | ⑧の最後の相対支持 | 初期と最後の馬別支持の相関 | 上位5頭維持率 |
| --- | ---: | ---: | ---: |
| 全馬均等の独立新規票：追随なし | **55.62%** | 0.999980 | 100% |
| 現在の人気の1.25乗で追随 | 65.77% | 0.999948 | 100% |

追随なしでも初期人気の順位の骨格と非常に高い相関が残る。**オッズに記憶が見えることは、社会的模倣が起きた証拠ではない。** 上の2行は完全な合成結果で、現実にどちらの型の投票者が何人いるかを推定したわけではない。300経路は実際の300レースではない。

## 7. 全136組で「単勝由来の相対組合せ支持」とワイドの形の乖離を見る

追加実装：[scripts/odds_cross_pool_global_async.py](../scripts/odds_cross_pool_global_async.py)。土曜15:37、日曜11:42、日曜12:18の3組について、次を全136ペアで計算する。

- W_ij = (1/ワイド下限オッズ) / 全136組の逆ワイド下限総和。組合せが重複的に的中するため、**Wは的中確率ではなく相対価格インデックス**。
- M_ij = Plackett–Luceモデルの P(i,jが共に3着以内) / 3。同じ3着内集合に3つの当たりワイドがあるので、全136組のMの合計は1。ただしPLの推定は単勝オッズに依存する仮定。
- 残差インデックス R_ij = log(W_ij / M_ij)。時間差 ΔR で、単勝から期待する組合せ相対分布と実際のワイド価格の形がどの程度別々に動いたかを記述する。

| 保存スナップショット間 | 136組の平均|ΔR| | 組間の残差順位Spearman | |ΔR| > log(1.25) の組 |
| --- | ---: | ---: | ---: |
