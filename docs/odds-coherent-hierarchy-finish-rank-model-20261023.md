# オッズの二層構造から、矛盾しない単勝・複勝・ワイド予測を作る

**2026-10-23｜モデルの数学的・ソフトウェア整合性が検証された段階。実際の予測的中率・収益率の改善は未検証。**

前段の[馬共通成分／ペア固有成分の市場価格指数分解](odds-pair-hierarchy-decomposition-20261023.md)では、2026年10月12日の京都8Rで完全ワイド55組の相対変化に馬共通成分が存在し、価格変化分散の72.64%を説明した（1組除外による誤差削減率58.80%）。**この指数を勝率と取り違えないことが重要。** そこで、今後実測データが増えて係数を学習するときも「勝馬は1頭・3着以内は3頭・的中するワイドは3組」という条件を壊さない、統一順位分布の基盤を実装した。

## 数理の接続

同じ時点の全頭単勝中間オッズから元のPlackett–Luce (PL) 順位モデルを計算する。i,j,k は相異なる馬番とし、順位の確率は

\[
P_{\rm PL}(i,j,k) =
\frac{w_i}{W}\frac{w_j}{W-w_i}
\frac{w_k}{W-w_i-w_j},\quad
w_i=1/o_i,\quad W=\sum_i w_i.
\]

ここで前後2つの券種の相対価格指数から得られる、馬別の変化成分a_iと残りのペア成分e_ijを用いて、順序付き上位3頭の全組み合わせに対して

\[
P_{\beta}(i,j,k)=
\frac{
 P_{\rm PL}(i,j,k)
 \exp\left[
 \beta_h(a_i+a_j+a_k)+
 \beta_p(e_{ij}+e_{ik}+e_{jk})
 \right]}{Z_{\beta}}.
\]

Zは全ての異なる順序付き上位3頭についての和。**β_h、β_pは将来のデータで学習すべき係数であり、今回の実測データから推定していない。** 入力のαとε自体も仮定したPL市場基準による相対価格指数からの量であり、生物学的な馬能力や投票者の因果的反応を直接計測したものではない。

この定義によって、全てのモデルパラメータでも同時に以下を満たす：

- 全馬の**単勝確率**の総和 = 1。
- 全馬の**連対（2着以内）確率**の総和 = 2。
- 全馬の**複勝（3着以内）確率**の総和 = 3。
- 全ワイドペアの**両馬3着以内の確率**の総和 = 3。
- 全三連複（上位3頭の順序なし）の確率の総和 = 1。
- 全馬単（1着→2着の順序あり）の確率の総和 = 1。

β_h=β_p=0 なら元のPLの単勝・複勝・全組合わせに**厳密に復帰する**。独立の二値ロジットで馬ごとの3着内確率を推定するだけでは、この質量の整合性を保証できない。なお、整合性があることは現実の的中確率に校正されていることを意味しない。

## 実オッズ入力＋**仮想係数**の感度例

京都8Rの13:44時点の全11頭の実単勝中間オッズを用いて、13:26→13:44の馬共通変化成分／ペア残差を固定。計算の動作確認のために**β_h=0.5、β_p=0.5**という恣意的な小さい係数を単独・同時に入れてみた。今回のデータで当たるように最適化したものではない。

| 未校正モデル条件 | 当時の単勝1番人気⑪のモデル単勝率 | ⑪のモデル3着内率 | ③–⑪が共に3着内となるモデル率 |
|---|---:|---:|---:|
| 元のPL（両係数0） | **20.287%** | **54.135%** | 16.933% |
| 馬共通成分β_h=0.5だけ | 19.304% | 51.466% | 15.446% |
| ペア固有残差β_p=0.5だけ | 20.278% | 54.099% | 15.199% |
| 両係数0.5 | 19.274% | 51.378% | 13.831% |

この表は**元のオッズと市場指数の変化を、整合的な着順分布へ変換するアルゴリズムの感度例**。本物の勝率ではなく、既存の予測市場に独立に勝てることや③–⑪ワイドが割安なことの証明でもない。係数の妥当性・一般性・時間的安定性は未検証。

[実装](../scripts/odds_coherent_hierarchy_rank_bridge.py)は、過去の保存価格から先に計算するため、京都8Rの当日の公式着順を読み込まない。レース結果・利益に合わせた係数の事後選択は実行しない。

## 何が新しくなったのか

「価格の非同調性には馬共通の変化がある」という**記述結果**だけでは、利用価値を検証できない。今回の共同順位分布なら、どの市場情報が1着・2着・3着・組合せへどう伝わるかを数理的に定義でき、同じ発走前情報のみを使用して異なるモデル間で**未来の結果をproper scoring ruleで比較する**道筋ができた。

将来複数の日付・競走で、次の比較を事前に固定する必要がある。

- M0: 最新単勝だけによるPL基準。
- M1: 最新単勝＋馬共通市場変化項（過去レースでβ_hを訓練）。
- M2: M1＋ペア固有残差項（過去レースでβ_pを訓練）。
- M3: さらに過去3時点以上の市場履歴、騎手・馬場・実績などの公表前特徴から事前登録した階層／閾値モデル。

レース日で学習と未来評価を分け、単勝Log loss、上位3頭の共同Log loss、複勝Brier、各券種の的中条件に整合した採点を行う。**55ペアを55独立標本として学習・検定しない。** 当該ソースで保証できないワイドの原更新時刻は推測で埋めず、HOLDする。ユーザーの発想である「初期オッズへの依存がある条件下で突然予測に役立つ」仮説も、M0–M3が新しい開催日に対して実際にスコア改善を示すかで初めて検証できる。
