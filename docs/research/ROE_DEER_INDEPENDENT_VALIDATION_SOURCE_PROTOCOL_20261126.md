# Roe deer external validation: public source audit

26 November 2026. Separate research branch; no horse manuscript causal claim changed. Scope is source acquisition and structural feasibility, not an empirical forecast or confirmation of information substitution.

## Published source evidence

- Gervais et al. (2020), *Pedigree-free quantitative genetic approach provides evidence for heritability of movement tactics in wild roe deer*, [paper](https://doi.org/10.1111/jeb.13594), [Dryad dataset](https://datadryad.org/dataset/doi%3A10.5061/dryad.dbrv15dxg), 23 Jan 2020. Public file listing has 5 files, including space-use and movement CSVs and a genomic relationship matrix. The paper describes monthly averages of daytime open habitat use, distance to road and movement speed. Month alone does not establish chronological records.
- Gervais et al. (2022), *Quantifying heritability and estimating evolutionary potential in the wild when individuals that share genes also share environments*, [paper](https://doi.org/10.1111/1365-2656.13677), [Dryad dataset](https://datadryad.org/dataset/doi%3A10.5061/dryad.6wwpzgn1j), 22 Feb 2022 version listing. The original paper analyzes genomic and home-range environment similarity in 293 deer; this is the authors' prior finding, not our new result. The public file list includes a reduced GRM, environmental similarity and repeated trait data candidates. The two releases may overlap in individual identities and are not independent external populations.

[Dryad terms, updated 20 May 2025](https://datadryad.org/terms) specify CC0 release of published datasets and scholarly citation, subject to terms. [Official API documentation](https://github.com/datadryad/dryad-app/blob/main/documentation/apis/README.md) describes public dataset, version, file and download GET routes. Only anonymous documented provider GETs; no bypass of 401/403/429, no credentials or guessed hidden download links. Local runtime DNS and web API access failed; this separate Actions job will make one bounded acquisition attempt per dataset. Confirm DOI, one listed version, expected public file list, explicit license if supplied, file hashes. Require review if version selection is ambiguous or actual download blocked. Do not conflate a successful workflow with acquired data.

## Data inspection before modeling

Use original public archives only. Inspect CSV/RData object types, dimensions and variable names; do not run scripts supplied in dataset. Check explicit unique labeled square matrices, finite values, row/column identity/order and symmetry. Compare candidate exact ID overlaps without exporting IDs. Identify candidate calendar year, date, year-month, and number of animals with repeated dated observations; month-of-year alone is not a valid chronology. Same-string IDs across releases are a candidate join, not proof of identity. Read original README semantics before accepting any endpoint or time key. No raw data, animal IDs, coordinates, matrix values or individual predictions uploaded.

If genuine dated habitat-use repeated outcomes, stable-ID GRM and independently determined environmental controls are supported, freeze a separate prediction protocol: early donor training, disjoint focal horses/deer for auxiliary training, chronological focal history, fixed genomic correction, later observed outcome and matched environmental/spatial correction. Compare forecast gains separately from within-individual overlap and sample membership. Environmental similarity calculated from the future outcome must not be treated as a prior predictor. Fit a regularized covariance kernel appropriate for signed genomic relationships; do not reuse sire-group count shrinkage blindly. Cohort support and exact temporal train/test windows are to be chosen from structural metadata only, before evaluating gains. If data are cross-sectional, or date/ID semantics cannot be established, HOLD temporal extension. No inference of heritability or causal habitat selection from predictive gains.

The source audit does not perform statistical fitting. No new raw data are committed; only bounded metadata and anonymous structural counts will be emitted if access succeeds. If provider blocks automated download, the user may obtain the files via the published dataset pages and upload the archives; do not bypass provider restrictions.
