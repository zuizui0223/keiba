# 父母の他馬履歴数を揃えた予測比較

**2026-11-22。PR72を確認した後の探索的解析。新しい均等頭数モデルの実測前に固定する。**

## 問いと設計判断

同父の履歴が同母より豊富だったPR72で、父母の予測差は履歴の頭数を揃えると
どう変わるか。同じ本人・条件情報と父母双方の明示的対数頭数を含むモデルで比較する。
対象は既に観測した2022–24年の資料で、未確認期間の検証や遺伝効果の推定ではない。

継続指示の下、以下は実装担当が選んだ条件である。両側に履歴のある馬だけへの制限は
標本を変えるため行わず、元の全標本を残す。一律1頭よりも残せる履歴を多くするため、
各出走条件で両側の最小頭数まで残す。元の係数を固定した特徴削除ではなく、各抽出で
再学習する。無作為抽出の誤差を把握するため32回を事前に固定し、結果に応じて回数を増減しない。

## 固定するもの

- Source A/BとPR70/72のSHA256、2018–21年学習、正則化α=100、標準化、馬均等学習重み、0–1クリップ。
- 元の厳格標本244,147出走・12,887頭・35,333競走。通期と2022、2023、2024年を全て報告する。
- 学習年tではt年より前の履歴のみ。評価の全3年は同じ2021年末までの履歴を使い、抽出キーのcutoff_yearも2022に固定する。
- 原モデルの全行M0/M1/M2成績、厳格標本QA、PR70とPR72の通期・年別全集計を絶対差1e−12以内で再現してから、新しい均等頭数の推定を行う。
- PR72参照 `japan-2022-24-parent-performance-channels-20261122.json` のSHA256は `18caad41d66257cc064de13051fbf65241493f869960cff2d05d7fde2968657f`。
- 元のMS/MDと同じ列集合・列順を使う。本人情報、条件情報、**元の父母両側の対数頭数と生の支持数列は変更しない**。変更するのは成績特徴2列だけ。

## 等しい頭数の履歴を作る

各対象馬・芝/ダート×400m距離帯について、同じ記録親を持つ過去の別個体を数える。
本人を除く父方頭数s、母方頭数dに対し `k=min(s,d)` とする。各側からk頭を重複なしで選ぶ。
k=0の出走も残し、両側の成績特徴を0にする。親不明は他の不明親とまとめない。
全兄弟姉妹は両方に入り得る。各他馬の過去成績の平均（正規化着順−0.5）が1回寄与する。

抽出seedは **2026112200から2026112231までの32整数**。
各過去馬の優先順位は次のUTF-8バイト列のSHA256 digestの昇順で決める。

```python
json.dumps(["keiba-equal-peer-v1", int(seed), int(cutoff_year), str(stratum), str(horse)],
           ensure_ascii=False, separators=(",", ":")).encode("utf-8")
```

同値digestは正規化した馬IDの昇順で解決する。同値時の微小な理論上の偏りを除き、
交換可能な擬似無作為優先順位による抽出である。Python組込みhashや結果の大小は使わない。
父母の側、親ID、対象馬ID、対象年・競走・日付、対象成績をキーに含めない。
同じcutoff・距離帯では両側・全対象馬で優先順位を共有する。同じ候補集合なら同じ馬を選ぶ。
本人を除いてから上位k頭を取る。各出走を独立に抽出して履歴量を増やさない。

本人の過去**全条件の出走数**をnとし、各側の成績特徴は従来と同じ形
`5/(n+5) * 選んだk頭の中心化平均成績の合計/(8+k)` とする。
従って片側を減らすと、使う馬と頭数に依存する縮約が共に変わる。
小さい側は全履歴を残すが、再学習によりその側の予測も変わり得る。

対象の結果列は履歴構築に渡さず、既存のCONTEXT列だけを渡す。
過去・対象間で馬の親組が矛盾する、日時の順序が不正、馬IDや距離帯が欠損する入力は拒否する。
生のs,dは既存特徴構築の頭数に完全一致することを確認する。中立的な成績0の他馬も数える。
基礎特徴と差替列は同じ一意なRangeIndexを持ち、行の入替えをラベルの重複で隠せないようにする。

## 学習と推定対象

各seedで全学習行の父母成績を作り直し、父方成績だけのMSと母方成績だけのMDを別々に再学習する。
評価時も同じseedを使う。元の全履歴MS/MD、MC、M0などは変更しない。
各出走で**32モデルの二乗誤差を平均**する。予測を平均してから二乗しない。
これは無作為に履歴を削減して学習する手順の平均損失であり、32モデルの予測を集めたアンサンブルではない。

各出走について、全履歴の父方優位を `F=L_MD,full−L_MS,full`、
均等頭数の父方優位を `B=mean_seed(L_MD,balanced−L_MS,balanced)`、変化を `C=F−B` とする。
主比較は **BとCの2つ×4期間＝8比較**。
正のBは父方だけの方が予測誤差が小さい向き。正のCは符号付きの父方優位の減少で、逆転も含む。
絶対差が必ず縮むという意味ではなく、比率への変換は行わない。

各側の平均損失変化 `E_S=mean(L_MS,balanced)−L_MS,full` と
`E_D=mean(L_MD,balanced)−L_MD,full` も記述し、`C=E_S−E_D` を確認する。
これらの側別変化に追加の有意差選別を設けない。
各期間でまず馬内平均、次に馬均等平均する。RMSEは平均した損失の平方根を報告する。
全履歴の7基準モデルと均等頭数MS/MDを並べ、特に2024年のM0比較を残す。

## 二種類の不確実性

評価標本について、32回平均した出走別B,Cに既存の馬×暦日クラスタ分散を適用し、
点別95%区間と8比較Bonferroni区間を出す。父群・母群の999回復元抽出、seed=20261122、
必要記録親群数30を別々の点別感度区間として併記する。不明親の馬別単独群を必要記録群数に加えない。
これらは**固定した32組の学習・抽出を条件とする評価区間**で、履歴資料を作り直す不確実性を含まない。

抽出に対する数値精度は、各期間の馬均等B,Cをseedごとに計算し、32値の標本SD（ddof=1）、
Monte Carlo標準誤差 `SD/sqrt(32)`、最小・最大を別途報告する。
同じ抽出回の全出走を一体として扱い、出走数×32を標本数にしない。B,CのSDは一致する。
各seedの期間別匿名集計も保存する。抽出SD/MCSEは生物学的な信頼区間ではない。
MCSEが点推定や区間の境界に対して大きい場合、無限抽出での結論は精度不足と明記する。

## 支持数と解釈

各期間で元の父母支持数を残し、kの馬均等平均、0・1・2–4・5+区分の出走数と重み割合を出す。
k>0の重み割合はPR72の「双方あり」と一致する。割合は馬均等に重み付けした出走で、
ユニークな馬の割合ではない。k=0でも他の係数の再推定によりモデル間予測は変わり得る。

頭数を揃えても、他馬の測定精度・独立性・時代・育成環境や血縁の深さは同一にならない。
全標本で片側のみの履歴を0にする変更も含み、「双方あり」集団だけの純粋な精度比較ではない。
32回を独立した生物学的再現と呼ばず、差の変化を遺伝・母性・情報利用の因果分解とは呼ばない。
公開は匿名集計のみ。原行、馬/親ID、名前、選ばれた馬のリスト、個別予測を出さない。
公式登録同一性、資料公表時刻、原資料の再配布権限の未検証状態は維持する。
