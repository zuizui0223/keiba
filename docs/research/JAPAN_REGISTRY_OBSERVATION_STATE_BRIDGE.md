# 将来の正式登録データ接続：観測されない馬の「理由」を捏造しないための契約

**2026-11-21：実データの登録・抹消を取得した結果ではなく、必要なデータの接続仕様。現在の二次資料については[2022→2024の出走記録経路解析](JAPAN_2022_24_OBSERVATION_PATHS_PROTOCOL.md)を参照。**

## なぜ必要か

現時点で「2024年に観測なし」と言っているのは、まず Source B の**固定された厳格な完走順位照合対象**に記録がない、という意味に過ぎない。より広いSource Bの有効着順記録に残っている場合もあり、真の競走非参加や引退を表さない。さらにSource B自体はJRA/NARの公式全登録馬台帳ではない。

JRA公式は競走馬の「登録／抹消一覧」を公開している（https://www.jra.go.jp/datafile/massyo/index.html）。JRAの馬主向けFAQは、抹消後の進路として地方競馬、繁殖、乗馬など複数の可能性を明示している（https://www.jra.go.jp/owner/members/faq/category_g.html）。したがって**登録抹消＝死亡、退役、繁殖失敗ではない**。JRA-VAN Data Lab.の競走馬マスタUMには血統登録番号、JRA登録／抹消年月日や抹消区分などが定義される（https://jra-van.jp/dlb/sdv/sdk/JV-Data4901.pdf）。同サービスは有料のライセンス対象であり、ソフトウェアの入手だけで第三者の個票配布許可が得られるわけではない。

## 次の3階層（今は未結合）

1. **解析対象の観測層**：2022年の候補12,755頭について、2023・24年の固定厳格完全順位出走記録、より広い有効出走記録、データ源ごとのカバレッジを区別。観測されなかった理由はこの段階では不明。
2. **競走登録・参加機会の層**：必要な許諾済みのJRA-VAN UM原本・更新版に、血統登録番号（10桁）、登録日、抹消日、抹消区分、スナップショット取得時刻、レコード作成年月日／版、原本SHAを持たせる。必要なら各年の実際の出走登録・出走取消・除外・NAR移籍の確認元を別に用意。**JRA抹消だけでNARや繁殖の状態を確定しない**。
3. **生物学的生活史の層**：死亡・負傷・疾患・繁殖用途・繁殖回数、行先／牧場、各年の真正な生存観測など、独立ソースが必要。これがなければ「自然選択・人工選択・適応度」へ因果解釈しない。

## 同一馬結合とpoint-in-timeの拒否条件

- 旧Source Aの馬IDとSource Bの馬IDは、2021年以前の複数日のレースを利用した**候補照合**であり、正式な血統登録番号の実測ではない。今回の解析から勝手に公式JRA登録番号を生成・推測しない。
- 許諾済みUMと連結する場合は、外部から得た正式番号が既存の元馬候補と一致することを**独立した2以上の識別手掛かり**で検証。名前だけ、冠名、父だけの一致では採用しない。複数一致や矛盾があればHOLD。JRAとNARは別名前空間で、登録状況も統一しない。
- UMの**現在の状態**から、2022年時点の情報として遡及代入しない。履歴の更新時点と2022/23/24の対象日を比較し、事後確定の登録変化はその変化後の情報としてのみ利用。2022→24年の事後説明と、2027年の真正レース前予測は別の目的変数・公開時点で扱う。
- 未来の「追跡」アウトカムも **JRAで登録あり／登録抹消／NAR転出確認済み／出走機会なし／データ未取得・不明** のような*記録上の状態*を原ソースに応じて分ける。死亡／生存・繁殖成功を勝手に補完しない。
- JRA在籍期間中の馬の部分集合だけを抽出する場合は、基準年の元の12,755頭から何頭が結合できたか、照合ができない馬の特徴がどう違うかを**観測バイアスとして追加報告**する。JRA-VANのUMを全国全馬の完全台帳と呼ばない。

## 実装の次のゲート

許諾済みで同一馬IDが確定できるUMと生涯の出走／非出走の資料が揃ってから、後年の各観測状態が「参加機会がなかった」「JRA登録が変わった」「他主催者へ移った」「記録不足」のどれに対応するかを限定的に比較する。資料が手に入らない間は、既存Source Bの**被覆・厳格抽出条件による違い**だけを数え、生物学的機構と区別する。
