# First observed context assignment versus later use: strong baseline and cold-information test

2026-11-24, follow-up to PR81. Prior occupancy results were robust against fixed shrinkage baselines; paired performance transfer was not. Test whether family-specific environmental assignment is visible at the first eligible observation of each year, after a learned history-rich comparator. Do not call this an animal's voluntary preference, genetic adaptation, or official debut.

## Frozen design before new results

Source A SHA and 2,092,836 classified starts / 90,962 horses parity. JRA turf/dirt 1600–1999m. Annual known-sire eligible counts 7,265/7,381/7,276 in 2019–21 must match PR81. First outcome is binary surface of earliest classified eligible start within each year. Reject ambiguous same-day first observations. Later outcome is turf fraction of remaining starts among horses with >=2 eligible starts; include observed first surface in its baseline. First and later endpoints differ in support, so no raw MSE effect comparison.

Feature cutoffs are Jan 1 of target year; prior histories include all earlier valid archive starts, JRA starts, and eligible context starts (counts, turf fractions, distance, relative rank, recency and last outcome). Add historical last and entry-recorded trainer's eligible peer turf fraction (exclude focal), recorded age/sex at first eligible entry and fixed count interactions. Entry metadata condition the comparison and are not verified available pre-entry. Current target results/annual start count do not enter first prediction. For descriptive strata distinguish no earlier eligible/classified history before Jan 1 from no earlier raw archive date at entry; raw first record is not official debut and may be subject to archive omissions.

Train fixed alpha=100 weighted ridge on 2016 through year-1 target blocks, opposite globally hashed horse half. Donor profiles use all earlier years of opposite horse half, average within each horse and then sire; minimum three donor horses, shrink n/(n+8). No held-year outcomes in features. Historical information can be reused across folds, so not fully independent. B = strong no-kin model; C = B + log donor count; F = C + centered shrunk same-sire signal and interactions with own eligible-history presence/count. For matched donors (training-only count ratio <=2, original count_match), replace F's signal at test only with paired other-sire signal, retaining recipient count and learned F coefficients. P is not a separately trained model, not a randomization test or true unrelated genotype.

Primary 2021 first endpoint, seed 20261124, all targets C-F paired MSE. B-F and P-F matched secondary; all groups and other seeds/year/later endpoint retained. 999 whole-sire conditional pointwise bootstrap if >=30 sires. No posthoc selection or simultaneous inference. If robust gain remains even with entry trainer and no earlier eligible information, prioritize family-associated allocation rather than interpreting family performance as a causal response. Explicitly retain null/negative and support failures. No betting models or ledgers changed.
