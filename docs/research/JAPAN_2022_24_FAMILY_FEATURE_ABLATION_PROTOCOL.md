# 親族の成績特徴と明示的な頭数特徴：2022–24年の固定資料による4条件比較

**2026-11-21。既存結果を見た後の探索的解析。独立した事前登録検証ではない。**
本手順は新しい2中間モデルの結果を見る前に固定する。過去に採点済みの
2022–24年を新しい未観測標本とは呼ばない。

## 問いと4条件

既存の小さなM1→M2改善に、親族の成績を使う特徴と、記録された親族の
頭数を直接使う特徴がそれぞれどのように寄与するか。新しい利用ゲートや
最良モデルを結果から選ばず、同一の評価出走で次の4条件を全て公開する。

| 条件 | 既存の本人・環境特徴に追加するブロック |
| --- | --- |
| M1 | なし。既存の強化本人履歴モデル |
| MC | C：`log_sire_relative_count`, `log_dam_relative_count` |
| MP | P：`sire_kin_history`, `dam_kin_history` |
| M2 | PとC。既存の強化親族モデル |

Pは単なる親族平均ではない。各父母側・芝/ダート×400m距離帯について、
本人を除く各馬の履歴順位平均を一度ずつ数え、次の既存特徴をそのまま使う。

`P = [5 / (n_own + 5)] × [sum(peer_mean_rank - 0.5) / (8 + n_peer)]`

したがって**Pにも本人・親族の頭数による縮約が含まれる**。この比較は
「親族の成績と頭数の生物学的な完全分離」ではなく、実装済みの縮約成績特徴に
**明示的な対数頭数特徴を追加する価値**、およびその逆の評価である。
同父・同母は遺伝、育成環境、出走・記録・繁殖選抜を同時に表し得る。

## 評価と誤差の分解

全期間と2022/2023/2024各年を別々に評価する。各期間内で各馬の出走の
重みを`1 / その馬の期間内出走数`とし、馬間を均等にする。M0=0.5も残す。
全体は各年のRMSEの単純平均ではなく、全期間の元出走から再計算する。

各出走の二乗誤差をLとし、正の値が改善になるよう定義する。

- P追加（Cあり）：`L_MC - L_M2`。主たる問い。
- C追加（Pあり）：`L_MP - L_M2`。もう一つの主比較。
- P単独：`L_M1 - L_MP`、C単独：`L_M1 - L_MC`。
- 全改善：`L_M1 - L_M2`。
- P配分：`0.5 × [(L_M1 - L_MP) + (L_MC - L_M2)]`。
- C配分：`0.5 × [(L_M1 - L_MC) + (L_MP - L_M2)]`。

最後の2つは追加順序を対称化したShapley型の**予測損失の算術的配分**。
各出走と馬均等平均でP配分+C配分=全改善を確認する。各モデルの本人特徴の
係数も再推定されるため、固定係数への因果的介入ではない。負値を維持し、
合計が小さい/負の場合も百分率で貢献を誇張しない。

## 依存と不確実性

主比較2個×4期間の8比較について、馬×暦日の2方向クラスター
サンドイッチ感度区間を求める。馬均等重みw、行別損失差d、平均θに対して
`q = w × (d - θ)`、`V = V_horse + V_day - V_horse×day`とする。
各成分には`G/(G-1)`補正を用いる。95%区間と8比較Bonferroni正規区間を
併記し、非正の分散や30未満の馬/暦日はHOLDにする。

別途、記録された父を単位として**父群ごと999回再標本化**し、その都度
馬数で割った平均を計算する（seed=20261121）。父不明は各馬独立の
singletonにする。30未満の父群はHOLD。これは2方向法と別の感度解析で、
父・母・競走日を全て同時に考慮した遺伝的推論ではない。学習済み係数、
資料・標本選択を条件とする近似区間であり、学習や選抜の全不確実性を含まない。
