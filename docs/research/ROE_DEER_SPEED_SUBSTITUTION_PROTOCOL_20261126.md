2026-11-26. Frozen before reading SPEED outcomes/fits; designed after the positive POH results in PR98, so this is an outcome-informed endpoint extension, not an independent population or confirmation of a priori multi-endpoint hypothesis. Use the same locked 2020 Dryad release, data_movement_roedeer.csv (1,856 records, 205 deer, exact labeled GRM joins). **Estimand:** squared loss for the recorded numeric SPEED variable on the same masked target within each evaluated deer, 0/1/3 nested other records. Do not assume a physical unit or actual observation chronology; no clipping or outcome-driven transformation. Finite values only. Same outcome-blind duplicate rule, >=4 distinct period cells, and >=100 targets. Donor/focal halves, same seeds 20261124 (primary) and 20261125/26, donor ridge age/month×sex, own residual shrinkage 3, GRM correction ridge 1, signed matrix, 999 conditional paired deer draws, 199 sex-blocked genomic label permutations. Identical calculations except raw SPEED instead of bounded POH, no clipping; no re-tuning. For each seed report gain 0 and change 3−0 with 97.5% intervals, all three gains and RMSE, label controls and exact identity. Keep negative or uncertain outcomes. Do not compare raw MSE magnitude across POH and SPEED, pool endpoints, claim independent populations, or infer heritability/causation. The source animals may overlap; analysis masks and membership are endpoint-specific. All prior caveats on spatial dependence, conditional inference and mutually dependent cross-fit donors apply. Raw data deleted before aggregate upload.

If SPEED fails either directional contrast, it is a boundary to the POH generalization, not a reason to search transformations or seeds. If both are supported under the frozen criteria, label as a within-source cross-trait analogue, not a second independent species replication.
