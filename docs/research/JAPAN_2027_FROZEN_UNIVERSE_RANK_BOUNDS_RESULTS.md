# 2027年の事前予測：選択的に観測されたレースだけを採点しないための実装結果

**2026-11-21、実装・架空データの検証。REAL 2027 JRA FORECAST = 0／LICENSED SOURCE VERIFIED = 0／OFFICIAL STUDBOOK CROSSWALK VERIFIED = 0。** これは予測能力の実測結果ではない。元の2022〜24年の事後研究から、次の前向き検証に必要な欠測防御を実装した記録。

## 実際に追加したこと

[2027年の元の予測凍結・採点台帳](JAPAN_2027_POINT_IN_TIME_LEDGER.md)のソース・モデル検証を再利用し、**最初に凍結した予測の全出走・全馬を分母にした評価**と、より広い事前予定レースリストに予測が抜けていないかの確認を追加した。

- 実予測が存在する前提で**未取得の結果も分母から消さない**。完全順位が公表されたレース、まだ結果がないレース、部分的な結果しかないレース、DNF・取消・欠損によって正規化順位が定義できないレースに分類し、**レース数と出走数を4分類すべて0件を含めて公開**する。
- 事前に得た予定対象レースをプライベートCSVで供給できるようにした。予測のない対象レースを検出した場合、**全対象の予測改善をHOLD**。レースが正式に適格と確認された日時が予測as-ofより後だった場合もHOLD。
- 結果がまだないレースは、**もしその全馬が1..Nの完全着順で分類されたなら**という強い仮定を明示して、あらゆる可能な着順への並び替えから、M1−M2とM0−M2の**馬均等MSE差の厳密な最小・最大値**を計算。馬の2027年予測出走回数で固定した重みを保持し、観測済みだけで重みを再正規化しない。
- 途中棄権や取消が出て、元の1..N着順応答が定義できない場合、**未取得の順位を捏造しない**。全対象の優位判定はHOLDとする。
- 既存の凍結予測のSHA256と公開コミットメントとの整合性、結果の公表時刻、同一馬・同一レースの重複を元の`score()`で検証。全予測レースが完全分類済みなら、**新たな上下限が一致し、元の馬均等RMSE二乗差に1e−10以内で一致**しなければHOLD。

## 数学的な方法の反証

各馬i、予測モデルB=M1（またはM0）、親族情報モデルM2のMSE差は

`w_i[(y_i-p_{B,i})²-(y_i-p_{M2,i})²] = 2w_i(p_{M2,i}-p_{B,i})y_i+w_i(p_{B,i}²-p_{M2,i}²)`。

順位`y_i`はN頭の全完走なら`0,1/(N−1),...,1`という並び替え。傾きの降順と昇順で最小・最大を計算する。架空2頭の`p_{M1}=(0,1)`、`p_{M2}=(1,0)`の場合、未取得レースでのM1−M2の馬均等MSE差は**−1から+1**まで変わり得る。同じレースの結果がないのに「M2優勢」とは宣言できない。

実装の[14の架空レース反証テスト](../../tests/test_ecology_japan_2027_denominator_rank_bounds.py)では、3頭レースの全6通りの完全順位を列挙して厳密下限と上限に一致すること、発表済み結果が一部だけ・0件・DNFのときに勝手に順位を補わないこと、未予測レースが分母に残ること、元の私有予測SHAが変われば拒否すること、元の競走馬・レースIDを集計に漏らさないことを検証する。

**これらの境界は「95%信頼区間」ではない。未取得レースが完全順位を持つという仮定下の決定論的な部分識別であり、実際のDNF・予測未提出・取消を解決する推定ではない。**

## 現時点の判定

- モデルの2027年実予測は未提出・0件。
- JRA-VAN/JRA/NARの正式許諾・登録ID、実レースの正しいknown-onと結果公開時刻は取得・確認できていない。
- 実際の対象レース一覧の完全性は、たとえprivate CSVが与えられても、GitHubに保存しただけで公的に確定しない。取得時刻の外部証明は[既存のサーバー時刻監査](JAPAN_2027_GITHUB_REAL_SERVER_REHEARSAL_RESULTS.md)が必要。
- 全体の出力statusは意図的に `HOLD_NOT_INDEPENDENTLY_ATTESTED_PROSPECTIVE_SOURCE_AND_UNIVERSE`。架空データで「全着順でM2優勢」となる場合も、実際の競馬研究の肯定的結果として報告しない。
- 同父・開催日などの統計的な非独立性を推定するのは、2027年実測が許諾・事前凍結・完整分類されてから。今回の順位の上下限に父系の信頼区間を足していない。
