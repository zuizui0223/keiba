# 2022→23→24: 同一馬・同一出走条件に固定した情報価値の年次変化と観測選択

**実競走資料を用いた完了済みの事後検証（2026-11-20 JST）。** 2022年選択済みMG、2018–21年M1/M2、原2022/23/24評価年は既知。これは新しい未開封将来予測ではない。**肯定・否定と共通支持の大幅な選択をすべて保存する。**

## 主要結論

3年とも同じ馬が同じ芝/ダート＋400m距離帯に出走した **4,636頭、5,895馬×条件セル**に固定し、馬内の出走条件構成も2022年に固定した。MG（2022年に本人履歴量でM1/M2を切替）に対する常用親族モデルM2の優位性は、**2023→24年に増す方向**で、馬単位399回再標本化95%感度区間がゼロを含まなかった。一方、2022→23年は逆方向の点推定だが区間はゼロを含み、2022→24年通算の区間もゼロを含んだ。**単調な親族情報劣化・個体の生物学的劣化の証明ではない。**

さらに2022年の候補12,755頭のうち2024年にも記録がある5,163頭と、ない7,592頭では、**2022年の時点からMG対M2の平均MSE差が異なる**。その群間差は馬単位再標本化区間でゼロを含まなかったが、2024年の収録可否は**生存/死亡/引退/繁殖・適応度ではない**。本人2021年以前の履歴量4区分の構成だけでは差の一部しか対応しない。

- Source B SQLite SHA256: 7c6717f6f081f957721396d1e0e7296b4be3eeaa2fe1a657b41a4b5358474be9。

- 固定2018–21 RidgeのM1/M2、2022年の結果だけで既に選択されたMG「本人の2021年以前の有効履歴数15以下＋同父母他馬の履歴ありならM2、それ以外M1」。今回その係数と閾値を再選択せず、元の年別M0/M1/M2/MGスコアと1e−8以内で照合。2024年のMG/M2の元RMSEは **0.319468/0.319257**で固定M0 **0.318059**より悪い。これを撤回しない。
- 各出走の signed gain は MG と常用親族M2の二乗誤差差 d=(y−p_M2)²−(y−p_MG)²。**正ならMGがM2より良い**。MSE尺度のため、年次差は厳密に加法分解できる。RMSEを足し合わせない。

## A. 完全に同じ馬×出走条件の3年間固定

各馬iの3年すべてに観測された粗条件sに対し、2022年の当該条件出走比 w(i,s,22)で2023/24年も標準化。毎年各馬を均等に重みづけしたMG対M2の平均MSE差は以下のとおり。

|---|---:|
| 2022年 | −0.000073440565 |
| 2023年 | −0.000023659862 |
| 2024年 | −0.000144483769 |

| 同じ馬・同じ粗条件の年次差 | 平均MSE差の変化 | 馬単位399回95%感度区間 |
|---|---:|---|
| 2022→23 | +0.000049780702 | [−0.000048091555, +0.000139945055] |
| **2023→24** | **−0.000120823907** | **[−0.000214007437, −0.000024613888]** |
| 2022→24 | −0.000071043205 | [−0.000186992341, +0.000047428727] |

3年の同一個体・同一条件を使うため、22→24年差＝22→23年差＋23→24年差が厳密に成立。**前半正・後半負という点推定の形は確認されたが、前半の区間がゼロを含むため非単調性の確証にはならない**。

全3年で共通条件があるのは、全3年に何らかの出走記録がある5,102頭の90.9%。共通セル内出走の年別割合は2022年 **38,480／120,381（31.97%）**、2023年 **43,888／80,939（54.22%）**、2024年 **33,644／42,827（78.56%）**。**2022年の約68%の出走が除外**されており、全馬集団に一般化しない。

## B. 後年の観測有無が2022年の「情報価値」を選ぶ

2022年の12,755頭を2024年にこの資料で出走が記録されたか否かで分け、**2022年のMG対M2の馬均等平均MSE差のみ**を比較。

|---|---:|
| 2022年全12,755頭 | +0.000047993904 |
| 2024年にも出走記録がある5,163頭 | −0.000029466976 |
| 2024年の記録がない7,592頭 | +0.000100671791 |
| **後年記録あり−なしの2022年時点での差** | **−0.000130138767** |
| 馬単位2群別399回再標本化95%感度区間 | **[−0.000217020611, −0.000035517236]** |

**本人の2021年以前の有効出走履歴数での対応（未出走の公式新馬とは異なる）**

| 本人の2021年以前の履歴数 | 2022年馬のうち2024年にも記録される割合 | 2022年における記録あり−なし群のMG対M2差 |
|---|---:|---:|

2022年の群間差 −0.000130138767 を、**過去履歴の4区分の構成** −0.000031827181（符号付き約24.5%）と、**同一区分内の2022年群差** −0.000098311587（約75.5%）に厳密分解。これは*事後的に後年の観測で選ばれた個体群*の差であり、競走成績や行動の遺伝因果・自然淘汰の寄与割合ではない。

## 本当に新しい意味

- **個体の履歴と親族履歴の予測価値が固定とは限らない**、という過去の示唆を、3年同一個体・同じ粗い出走条件で限定的に強化。ただし2023→24年の負方向以外は95%感度区間がゼロを含む。
- **後年にも現れる個体を選ぶ行為自体が、過去にさかのぼって予測モデルの優劣を変える**ことを実際の2022年データで示した。これは長期個体追跡研究一般の informative observation / selective follow-up の問題と接続する。
- しかし、観測の欠損は引退・競走条件変更・データ収録差・疾病・移動などと未分離であり、この観測選択を*生物学的選択*とは呼べない。同じ粗条件でも、相手、騎手、調教師、厩舎、年齢、馬場の含水、競走間隔、情報鮮度が異なる。
- 399回の**馬単位一方向**ブートストラップであり、レース日・父系などの多方向依存は同時に補正していない。区間は因果的・確認的な95%信頼区間ではない。
