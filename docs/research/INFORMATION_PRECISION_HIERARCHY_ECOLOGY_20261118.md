# 個体情報・親族情報・市場情報の精度階層：実測の再照合と反証可能な数理仮説

**2026-11-18 / 生態学・進化生態学の数理展開。既存実測の再計算と、解析的ガウスモデルの「別々の証拠層」を接続する。新しい実馬レース・DNA・時系列オッズは取得していない。モデル上の予測は生態学的効果や遺伝率の実測ではない。**

研究全体の主題：
> **個体自身の観測情報が少なく・古いとき、血縁者という代理情報の追加価値は増えるか。その情報は遺伝性・共有環境・市場の評判のどの経路に由来し、市場が新情報を受け取る時間順序でどう変化するか。**

統合した [観測証拠](INTEGRATED_KINSHIP_GENOME_INFORMATION_MARKET_20261118.md) に対し、正の結果のみ抽出せず、2024年と2026年の負の結果を数値ゲートとして維持する。

## 1. 実データの結果：2026年の条件を揃えた情報更新比較

[事後4条件解析の実測集計](../evidence/japan-2026-own-kin-factorial-empirical-20261117.json) を再読み込みし、2026年同じ**232頭・480出走**の学習係数を変えない条件で、次を検算した。

| 2026年・正規化着順の個体均等重み RMSE | 通常モデル＋家族特徴 | 強化モデル＋家族特徴 |
|---|---:|---:|
| SS：本人も親族も2021年までの情報 | 0.320302 | 0.318075 |
| FS：**本人だけ**レース前日まで更新 | 0.276899 | 0.274929 |
| SF：**親族だけ**レース前日まで更新 | 0.318210 | 0.315925 |
| FF：本人も親族もレース前日まで更新 | 0.276427 | 0.274423 |
| FFに対応する**親族なし** | **0.274782** | **0.274706** |

通常モデルのSS→FS改善 **0.043402250** に対しSS→SFは **0.002091261**。比は **20.75**。強化版は **0.043145547 / 0.002149693 = 20.07**。ただし、これは同じ選択集団の**モデル比較RMSE**であり、因果寄与率・遺伝的分散比・母集団の安定した情報比ではない。

本人情報をすでに新しくしたFS→FFでは、古い親族情報を新しくすることに **+0.000472459（通常）／+0.000506616（強化）** の小さなメリットはあった。しかしその親族追加版FFと**親族なし**の最新本人情報モデルを比較すると、通常は **−0.001644488（悪化）**、強化は **+0.000283036（不確実）**。**「親族情報は新しい方が良い」≠「親族情報は採用した方が良い」**。

別時期の [2022–24実競走](JAPAN_2022_2024_JOINT_STRICT_STRONG_RESULTS.md) では親族履歴の予測上積みが+0.000322454（別資料・主モデル）または+0.000261580（完全順位・強い本人履歴）。親組入替19対照は全て実際の親族効果より小さかったが、経験的片側plus-one pの下限は**0.05**で事後感度分析である。さらに厳密な2024年単年では、親族モデルも単純中間順位のベースラインに敗れた。

2026年の別資料・独立期間で古い2021年までの親族履歴を加えるとRMSEが**悪化**したこと、当初の全学習モデルが中間順位の基準に負けたことを撤回しない。後に追加された2026年の更新解析は**元の2026年結果を見た後の事後分解**であり、新しい独立追試にしない。

## 2. なぜ本人の情報が増えると血縁者の予測価値が小さくなり得るか

未観測の潜在的な競走状態を \(\theta_i\) とし、その事前分散を \(\tau^2\) とする。自身の過去の個別観測を \(O_{i1},\dots,O_{in}\)、親族・代理情報を \(K_{i1},\dots,K_{im}\) と置く。単純化した**ガウス型の独立ノイズモデル**を次のように仮定する。

\[
O_{ij} = \theta_i+\epsilon_{ij},\quad
K_{ik} = \beta_K \theta_i+\xi_{ik},\quad
\operatorname{Var}(\epsilon)=\sigma_O^2,\quad
\operatorname{Var}(\xi)=\sigma_K^2(1+\Delta t/T).
\]

**\(\beta_K\) は他馬成績という代理信号の予測的な負荷量で、血統A・SNP関係G・遺伝率でも因果遺伝の係数でもない。** 親族履歴の古さを \(\Delta t\)、減衰スケールを \(T\) とする。ノイズが独立でその分散を既知とするという、現実には厳しい仮定の下で、

\[
P_O=\left(\tau^{-2}+n/\sigma_O^2\right)^{-1},\qquad
P_{O,K}=\left(\tau^{-2}+n/\sigma_O^2+
\beta_K^2m/\{\sigma_K^2(1+\Delta t/T)\}\right)^{-1}.
\]

\[
\boxed{\Delta V_K=P_O-P_{O,K}\ge0},\qquad
I(\theta;K\mid O)=\tfrac12\log(P_O/P_{O,K}).
\]

**演繹的に導かれる予測**：その他の精度を一定に保つと、本人観測回数 \(n\) が増え、また親族信号が古くなるほど、親族情報による分散減少 \(\Delta V_K\) は小さくなる。\(m=0\) または \(\beta_K=0\) ならゼロ。これは**潜在形質の理論的な最適推定リスク**であって、実馬のRMSEや市場予想確率ではない。

[解析とテストを実装したコード](../../scripts/ecology_information_precision_hierarchy.py) では、架空の固定条件 \(\tau^2=1,\sigma_O^2=1.5,\sigma_K^2=1,\beta_K=0.4,m=4,T=365日,\Delta t=30日\) を用いた。この条件で理論的な分散改善は本人観測0件で **0.371619**、10件で **0.009341**。実測の「約20倍」をこの架空パラメータへ当てはめて推定していない。

### 反例：血縁情報が実際に生物学的新情報を持つとは限らない

本人情報 \(O=\theta+\epsilon\) と代理情報 \(K=0.5\theta+\eta\) について、
\(\mathrm{Var}(\epsilon)=\mathrm{Var}(\eta)=1\) で \(\mathrm{Cov}(\epsilon,\eta)=0.5\) とすると、\(K=0.5 O+\zeta\) のような冗長な代理信号が成立する。**Kと真の状態θは周辺的に相関していても、本人情報Oを条件付けるとKの追加情報はゼロ**になる。コードは正定値な誤差共分散を持つガウスモデルで、\(\Delta V_K=0\) を厳密に確認する。

ここでの誤差相関は、同じ厩舎・飼養条件・相手組合せ・同じ時期の測定による情報の重複にも対応し得るという**概念上の反例**である。特定の競走馬でその環境効果を測定したわけではない。この反例のため、実際の親族履歴効果が正でも「加算遺伝的効果」と呼べない。

また、理論的に正しい最適ベイズモデルでは有効な情報を増やしても**期待二乗誤差は悪化しない**。しかし2026年の固定Ridgeモデルでは親族を追加すると悪化した。これは単純な理論の反証ではなく、情報源の誤差相関・古さ・学習係数のずれ・選択集団・出力定義等の影響を検討すべき証拠である。

## 3. A・G・候補遺伝子を親族情報の代理変数から分離する

血統行列Aは、系譜記録が揃っている場合に期待される相加的遺伝関係。今回のWikipedia由来Aは**母リンクが極端に欠損した部分系譜**であり、無経路は無血縁の証拠ではない。

実測SNP由来Gは**370頭×353,249常染色体SNP**の標本内関係であり、12,919頭の競走履歴・38メイショウ記事と**同一馬IDの結合がない**。親族の競走履歴から得た予測情報と匿名SNP関係を結合して遺伝効果・遺伝率を推定したとは主張できない。

一方、MSTN g.66493737C>Tと最適レース距離の関連は独立の先行研究（Hill et al., 2010, *BMC Genomics*, DOI [10.1186/1471-2164-11-552](https://doi.org/10.1186/1471-2164-11-552)）で実証されている。しかし**本リポの匿名DNA検体で競走馬の同一成績と直接結合した新しいMSTN効果はない**。将来の同一ID×SNP×馬場×距離×反復成績で、候補座位による*距離反応規範*を検証すべきである。「適応的」と呼ぶなら、競走成績だけでなく繁殖・健全性・選抜圧を分けて扱う。

## 4. 市場情報の階層は別の集団の情報処理である

**馬がオッズを参照して走行を決めたという実証は存在しない。** 価格更新は人間の投票集団が情報を評価する過程であり、馬の個体行動・遺伝からの別レイヤーである。

~~~mermaid
flowchart LR
    AG["Bloodline A / genotype G"] --> L["Latent performance traits"]
    Env["Breeding farm / stable / rider / course"] --> L
    Env --> K["Observed relatives' race histories"]
    L --> O["Own observed race history"]
    L --> Y["Race outcome"]
    K --> Bio["Bio predictive model M2"]
    O --> Bio
    O --> First["Early public market assessment"]
    K --> Rep["Pedigree reputation"]
    Rep --> First
    First --> Q["Later public odds q(t)"]
    Updates["New public info / private opinions"] --> Q
    Q --> Later["Subsequent collective market judgment"]
    Y --> Selection["Breeding decisions"]
    Rep --> Selection
    Selection -. "future generations" .-> AG
~~~

遺伝・血縁の階層（世代）、本人の競走状態（週〜月）、出走条件（前日〜分）、人間のオッズ（分〜秒）、育種（数年）を区別する。競走勝敗の観測と人気の評価は同じアウトカムではない。

今回の保存済み**9レース117頭の単一単勝オッズスナップショット**から、馬群の候補分散を**逆数オッズ正規化のSimpson有効支持頭数／出走頭数**で表すと、実際の範囲は **0.1747〜0.7588**。最も支持された馬の相対逆数オッズ重みは **0.1375〜0.5616**。これは**市場状態の横断的な不均一性**を示すだけで、支持が変化したこと、群衆追随、閾値・臨界現象、投票票数の実測ではない。出走馬の血統登録IDと結合していないので生物情報が市場に「伝わった」証拠でもない。

後に真正の時点付き全頭単勝時系列が得られたら、初期時点では「本人履歴・公開血統評判・公表環境条件→q(t0)」を、後続時点では「q(t)・新たな公開情報・私的予想→q(t+Δt)」を、**異なる予測問題**として比較する。初期q(t0)を使って初期q(t0)を予測する自己参照は禁止。社会的情報の実証には、個々の市場更新時刻と新情報の到着を分け、追随ゼロ・連続追随・真の閾値を事前固定した比較が必要となる。

**市場情報価値を生物学的な情報価値と直接引き算しない。** 生物側の正規化順位RMSE改善は、勝率予測の対数損失/Brier改善、投票支持率の更新や利益とは別である。確率的に校正された未来勝敗予測を得て初めて、市場が持つ既知情報の上に親族・本人情報が上積みするかを検証できる。

## 5. 2027年の真正の未来予測で反証する設計

研究の実証可能な第一段階（行動/情報生態学）を次の予測にまとめる。**すべて将来レースの情報公開時刻・馬ID・検証期間を外部に証明できる場合だけ**実施する。

| 仮説 | 必要な比較 | 反証される例 |
|---|---|---|
| H1：本人が観測不足なら親族の情報価値が高い | 同じ未来レースで、本人の真正な既出走件数が0 / 1–3 / 4以上の各群に対し M2−M1 の追加誤差減少を比較 | 個体履歴が十分な群だけで改善、観測不足群でゼロ/負 |
| H2：親族履歴が古いと価値が落ちる | 同じ本人履歴を固定し、親族記録が最後に観測された時刻と過去走数を同時にモデル化 | 古さによらず改善ゼロ、あるいは時期効果が別データ源の鮮度だけで消える |
| H3：血縁という代理情報が共有環境と独立に役立つか | sire+dam組の出生群・厩舎/生産者条件付き置換、同厩舎他馬対照、馬齢・馬場/距離統制 | 血縁モデルが厩舎代理・偽親族・源の欠損だけで説明可能 |
| H4：血統の評判と実測能力は異なる市場チャネルか | 全頭・同一馬IDの初期支持q(t0)と後続q(t), 新情報到着、事前凍結したオッズモデル | 血統評判は価格に独立した増分を持たず、以前の価格や近走で説明される |
| H5：市場期待が育種選択に帰還するか | 年代別の種付け頻度・実競走成績・価格・仔の変異頻度/G等 | 人気と繁殖頻度の対応が既知の種牡馬実績や制度変化を条件付けると消える |

**主検定（未来の本物の競走でのみ）**：固定した同一出走群で、M0=無学習の中間順位、M1=本人の公開済み履歴・競走条件、M2=M1+同父/同母の他馬履歴を比較する。M2がM1とM0の双方よりRMSE小で、サポート・年/季節・馬齢・厩舎・母系の感度分析に耐えなければ一般化しない。記録上の過去走なしは、公式のデビュー馬とは限らない。父系・馬ID・レース日単位の依存性、選抜と着順の欠測を同時に監査する。

候補遺伝子×距離のモデルと市場ABM/PDEは**それぞれ独立のデータ接続と別の評価指標**を必要とする。親族履歴の正の予測結果だけで三者を一つの因果効果として結び付けない。
