# Parent information on the daily common ability scale

26 November 2026. Secondary research following PR109 precision limits, frozen before examining new family-ability fits. Same SHA-locked 2010–21 classified JRA source and exact PR107 calibration, support and Brier parity. Parent identity is a recorded direct sire/dam label, not verified pedigree or genome. Register nonempty labels after each observed race day only; never use target-day or future labels in predictions. Missing IDs never grouped; conflicting historical labels permanently quarantined. For each active horse, compute each same-parent other-horse rating mean from horses with previously observed parent label and earlier classified starts, using their daily global ratings decayed to target day. Exclude focal horse from sum and count. Each distinct donor contributes once. Signal for parent channel is sum(other ratings)/(k+8) × 5/(n+5), where k distinct historical peers and n focal prior recorded starts, zero when no peer. Both shrinkages fixed a priori; units are daily logit ability score. This is a candidate auxiliary predictor, not a genetic breeding value.

Fit three nested antisymmetric pair-logistic models on 2019 connected first meetings only, 217,613 pairs required: O = original daily naive, global and surface rating differences plus log1p prior starts difference; N = O + parent known-label indicators and log1p prior peer counts, as differences; F = N + sire and dam ability signal differences. Race-equal weights, no intercept, RMS scaling without centering, fixed penalty .001 on mean logistic loss, fixed optimizer convergence. No target retuning. Original daily global/surface scores retained as separate references. Primary two F-vs-N Brier gains for 2021 both exactly one prior recorded JRA start and win, and both exactly one prior recorded JRA win (first meetings, connected pre-day). 2020, general first meetings, both 1–3 prior starts and both >=4 starts, count gain and other contrasts secondary. Minimum 100 distinct pairs and 30 days, conditional 97.5% whole-day percentile intervals, 999 draws. Report all support denominators including zero-peer cases and frozen coefficients. No selecting subgroup after results, no claim that a nonzero sign proves genetics; fixed history shrinkage is imposed, differences by depth not a formal moderation test. Other-horse network scores can share historical races with focal horse even after self exclusion. Count control does not ensure matched management, environment, kin or independent information. Missing/unknown labels not biological unrelatedness. No official career or entry census, absolute speed, physiological capacity, prospective forecast or wagers. Conditional intervals omit shared graph/fitting/horse dependence. Source already inspected; no raw data, identifiers, ratings or predictions redistributed.
