# メイショウ以外への拡張：冠名38群・父ID20群の実競走予測

2026-11-14。前回の拡張コードを実データで実行した。**100頭以上の18冠名群では、親族情報が本人履歴だけを改善したのは17群だが、中間順位固定を上回ったのは5群。最も一貫した探索的候補はタガノ群。実父ID20群では3群だけが中間順位を上回り、いずれも点別95%区間は0を含んだ。**

## 1. 変えていないものと、新たに計算したもの

原本は公開二次資料 ayuser / Horse Racing in Japan の2010–2021アーカイブ。元217万144行から採用した90,962頭・2,092,836行を使い、2019–2021年の34,676頭・524,998行・48,341レースについて、PR45の固定済み7モデルの予測を再現した。新しい係数の選び直しや群別のモデル学習は行わず、全21個の年別RMSEと全7個の合算RMSEが元結果と1e-10以内で一致することを先に検証した。

冠名候補は前回固定した38種類の文字列で、対象は計4,513頭・66,351行。残る30,163頭・458,647行はOTHER_UNMATCHEDに残す。これは未指定の冠名や末尾冠名なども含むため「冠名なし」とは呼ばない。分類が同じ馬ID内で食い違った例は0、元のメイショウ判定との不一致も0だった。馬の同定と父母結合には元資料のIDを使い、馬名の類似検索は使っていない。

冠名群は確認済みの所有者・生産者・遺伝的クレードではない。父系20群は2019年より前に観測された異なる産駒数だけで選び、2019–2021の成績の良さで選択していない。父の表示名は同じ父IDに記録された名前である。

## 3. タガノは探索的候補。ただし「冠名の遺伝効果」ではない

タガノ138頭・1,134行の中間順位との差は0.020689、本人履歴との差は0.021148だった。父を共有する集団で別々に再標本化した点別95%区間は中間順位との差で+0.006044〜+0.034905、日付クラスタでは+0.010546〜+0.031195。年別改善差は2019年+0.015173、2020年+0.002999、2021年+0.005991で、3年とも正だった。

同群で初回記録88頭の改善差は+0.029137。JRA部分は+0.021849、NAR部分は+0.009366だが、JRA127頭／NAR41頭には重複して両方へ出走した馬がいる。独立した馬集団の追試ではない。

ここでは38群を比較した後の探索的記述であり、点別のクラスタ区間は多重比較補正済みの有意差ではない。調教、馬齢、クラス、距離、馬場、競走への選抜などの共通要因をすべて調整した実験でもない。タガノに特別な遺伝的能力がある、という結論は出さない。

## 4. 冠名よりも本人履歴・開催区分で状況が変わる

シゲル、テイエム、デルマ、クリノは合算で基準超えがあったが、各点別95%区間は0を含む。中央／地方に分けると方向も変わる。

| --- | ---: | ---: |
| シゲル | +0.034333 | −0.009426 |
| テイエム | +0.024469 | −0.008894 |
| デルマ | +0.034519 | −0.009035 |
| クリノ | +0.029229 | −0.008471 |

18群のうちJRA部分で親族モデルが基準を超えたのは13群、NAR部分では5群、解析対象内の初回記録では12群。これらの部分集団は小さいものもあり、個体の転籍等で独立でもない。**冠名だけで予測効果をまとめるより、本人の情報量と競走環境の違いを検証する必要がある**という示唆であり、開催区分が因果的に改善を生むとは判定しない。

デルマでは調教師単独0.316355が調教師＋親族0.319007より良く、クリノも調教師単独0.319076に対して併用0.319397。親族を足せば常に良くなるわけではない。

同じ馬ID内の冠名分類の矛盾0、旧メイショウフラグとの差0を確認した。非メイショウ実データは34,144頭・517,101行。RMSEは中間順位0.325014726、本人履歴0.330555367、親族0.327393913、調教師＋親族0.325566013で、前回の条件付き算術値と一致した。この部分も基準には未達。
