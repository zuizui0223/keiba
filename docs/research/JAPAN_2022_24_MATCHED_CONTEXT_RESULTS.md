# 同一馬×共通出走条件での2022→2024年親族情報ゲート失敗の実測検証

**2026-11-20 / 実データ、事後的・記述的検証。** 厳密な2022–24年の元競走結果を使い、新規2027未来予測や遺伝の因果推定ではない。

## 結論

**2022→2024年の親族情報ゲートMGの常用親族M2に対する予測優位性は、同一馬かつ同じ芝/ダート・400m距離帯に限定しても負方向の点推定が残った。ただし馬単位399回再標本化の95%区間はゼロを含み、頑健な条件内悪化とは判定できない。**

本人の歴史情報量だけの区分構成変化では説明し切れなかった以前の年差を、さらに粗い出走条件の共通支持に限定して試した。**残った負値は検証済みの「行動変化」や遺伝効果ではない**。同じ馬・同じ距離帯でも、馬場状態、競争相手、騎手、調教師、厩舎、体調・年齢、出走に残る選択と情報鮮度が変わる。

## 馬均等重みの実測MSE差

1出走の有利さを d=(y−p_M2)²−(y−p_MG)² と定義。**正ならMGがM2より良い**。順位は元モデルの正規化完全着順スコアを利用。2022年の各馬の共通条件別出走重みで2024年を標準化した同一馬の対応比較を主推定量とする。

| 指標 | 実測値 |
|---|---:|
| 2022年：共通条件に限ったMG対M2 MSE差 | −0.000074301667 |
| 2024年：2022年の条件構成で標準化したMG対M2 MSE差 | −0.000145179007 |
| **同じ馬×共通条件の標準化年差** | **−0.000070877340** |
| 馬単位399回再標本化95%感度区間 | **[−0.000186580049, +0.000027066248]** |
| 2024年：当年の共通条件内出走構成によるMG対M2 MSE差 | −0.000132996808 |
| 当年構成による2022→24年差 | −0.000058695141 |
| 同じ馬内の出走条件構成変化の寄与（2022年条件内差固定） | −0.000013748918 |
| 条件内の誤差差変化の寄与（2024年条件構成固定） | −0.000044946223 |

最後の2項は **−0.000058695141 に加算一致**する。算数の恒等式であり、分散分析や因果的な媒介比率ではない。負の標準化年差は観測された方向として記録する一方、区間がゼロを含むため「同じ馬で年をまたいで劣化した」と断定しない。

元の全頭（共通条件に限らない）成績もそのまま維持する：

| 年 | 固定中間順位 M0 | 常用親族 M2 | 2022年選択ゲート MG |
|---|---:|---:|---:|
| 2022 | 0.322132 | 0.309804 | **0.309727** |
| 2024 | **0.318059** | 0.319257 | 0.319468 |

元2024年のMGとM2がM0にも負けた**否定結果は維持**する。先の「約42%集団選択・約58%同一候補馬の年差」も同じ全頭データの記述的恒等分解であり、今回の共通条件に限定した数値とそのまま足し引きしない。

## 研究としての位置づけ

観測され続ける個体の選択、観測条件の移動、同じ個体と条件での予測誤差変化という**3階層を混同しない解析設計**は得られた。しかしデータは事後検証で、本人・親族情報の真の時点、馬の永久的な行動差（個体反復性）、血統A/ゲノムG/特定座位、繁殖成功/適応度、市場の実オッズ時系列と結合していない。2027年の元時点認証付き・未使用出走での独立追試が次の実証ゲートとなる。
