# 2022–2024 親族履歴の価値は、本人の情報量と親族情報の古さによって変わるか

**設計日：2026-11-18。完全に事後的な層別分析。2022–24年の全体効果も、2026年の個体×親族情報更新の結果も既に閲覧した後に設計している。未来の独立検証、遺伝的因果研究ではない。**

## 生態学的な中心命題

同じ個体が十分に観測される前は、他個体、特に近い系譜の個体についての記録が、その個体の状態を知る代理手がかりになり得る。しかし本人の記録が多い場合や、親族の記録が古い場合、その追加情報の価値は減り得る。これは **private information vs proxy information** の問いであって、親族履歴の効果を相加遺伝効果と呼ぶものではない。

これまでの実測：
- 2018〜21年の元資料で係数を学習し、別資料2022〜24年の12,919頭255,484出走で親族履歴を足すと RMSE 約 +0.000322 改善した。
- 完全着順35,333レースに制限して、強い本人履歴モデルを用いると、12,887頭・244,147出走で増分 +0.000261580（馬単位ブートストラップ95%約 +0.000077〜+0.000439）。ただし2024年単年ではM2は固定中間順位ベースラインに敗れた。
- 2026年の別資料では古い親族情報を足すと予測が悪化した。本人の最近の情報を更新した後の親族履歴増分は小さく、2026年の同じデータに対する事後解析なので新しい独立性はない。

今回の問いは**正の層を探すことではなく、親族情報による追加誤差改善が本人の観測数・親族の記録の古さ・他馬履歴数と一貫して関連するか**を、2022–24年の固定評価集団で記述的に分解すること。

## データと不変条件

三本の資料を追加で探したり、2022–24年の結果を再学習しない。以前の成功runと**同じ原本SHA**を利用する。

1. Source A（2010–2021年、学習と過去履歴）：ZIP SHA256 c72d280ce82b583686caca6773fd1a7589917f9b10b96a25f8d4e96f9b7a4a8f。
2. Source B（2022–24年の歴史的な別資料、着順・馬IDの照合）：SQLite SHA256 7c6717f6f081f957721396d1e0e7296b4be3eeaa2fe1a657b41a4b5358474be9。
3. 名義＋**2021年以前の別々の競走日2日以上**でA↔B候補同一馬を照合（公式登録馬IDとしての確定ではない）。
4. Source Bで連続1…Nの完走順位と宣言頭数が一致したレースに制限。完全順位評価の原本**244,147出走・12,887頭・35,333レース**が再現しなければHOLD。
5. 同じ2018〜2021年学習のリッジ係数・本人履歴8＋年齢/性別/前走経過日数等の追加、同父／同母の他馬履歴4特徴、正規化着順、個体均等重みを維持。M1=0.31242944828841407、M2=0.3121678685067159、M0（中間順位）=0.3217441421829057（RMSE）との1e−8パリティを満たさない限り層別分析を出さない。
6. **層別指標はすべてSource Aの2021年以前に記録されていた日付・馬/父母IDのみ**から計算。後年の本人・親族の実際の競走成績は使わない。データの作成年月日は真正の結果公表時刻の証明ではない。

## 出走前に利用可能な記録から作る四つのモデレータ

| 指標 | 算出 | 公表する層 |
|---|---|---|
| 本人の記録済み競走数 | Aに収録された本人の過去レース | 0–3、4–7、8–15、16+ |
| 同父または同母の**他馬**の記録済み頭数 | 馬場×距離帯が一致するセル、各他馬は1回だけ、父方/母方の二重計上を防ぐため最大の片側人数 | 0、1、2–4、5+ |
| 本人の最後のA記録から結果までの経過日数 | Aにある本人の最後のレース日 | 0–365、366–1095、1096+ |
| 同父または同母の他馬の最後のA記録から結果まで | 各父母×環境セルで**本人自身を除いた他馬の最新日付**。なければ欠測を独立層とする | 無記録、0–365、366–1095、1096+ |

この標本は**資料間の同一馬候補照合に2021年以前の生競走イベント2日以上**が必要だが、資料Aの利用可能な着順・馬場条件などのフィルタ後にモデルへ残る有効な過去走は**0件または1件の場合もある**。それらは独立の欠測層に残し、公式新馬・生涯初出走とは呼ばない。したがって**正式な初出走馬について結論は出せない**。親族ID欠損を「血縁ゼロ」として分類してはならない。固定された過去資料が2021年までなので、例えば2024年の「親族の記録が古い」は単に古いソースまでしか読んでいないこととも関連し、実際に親族が何年も出走していなかった証拠ではない。

## 結果の判定と負の結果の扱い

独立した「本人記録数×他馬履歴数」「本人記録数×親族情報経過時間」「本人記録数×結果年」について、**再学習せず**同一の固定M1・M2予測を層別して予測誤差を比較する。

- 主記述指標：(Deltamathrm{RMSE}=mathrm{RMSE}_{M1}-mathrm{RMSE}_{M2}) 及び同じ個体均等重みでの平均二乗誤差の差。**正が親族履歴による改善**、負は悪化。
- 各層120出走、30頭、15異なるレース日未満なら数値を出さずHOLD。
- 馬単位・レース日単位で別々に199回再標本化した区間を**事後的な感度分析**として付ける。相互作用の因果信頼区間や複数比較補正済みp値ではない。複数層の区間を見て「有意に役立つ特定層」を後付けで確定しない。
- 2024年単年の親族モデルが中間順位に敗れる結果を**必ず保持**。親族モデルが親族なしには勝っても、中間順位より悪いなら運用上の予測価値は支持しない。
- 兄弟や父系の記録は生産者・調教師・飼養方針・選抜を共有するため、部分A/Gの遺伝的効果とは呼べない。厩舎・生産牧場の共有環境はこのA↔B資料で適切に統合できていない。

**H1の支持といえる次段階の本物の証拠**は、今後の未観測競走で、本人の実在する履歴数×親族のデータの時点を出走前に取得して、固定M2が固定M1及びM0の双方を上回る追加予測を再現すること。現段階の結果はその予測の**探索的な監査**である。
