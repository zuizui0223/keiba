# 実市場の集中度と投票者ABM：血統情報をどこへ接続するか

**2026-11-15。実データの範囲と仮想ABMを完全に分離した研究結果。**

## 結論

2026-10-18の保存済み**9レース・117頭**の単勝オッズから、レース内相対支持率と市場集中度を実測計算できた。一方、時間変化・血縁との関係は**測定できない**：原資料に**horse_id・父母ID・真正の配信元時刻が一件もなく、メイショウ冠名馬も0頭**。現状の日本実データで「親族効果がオッズに表れた」と結論するのは誤りである。

実測9レースを投票者ABMの初期値に使い、架空の事後投票を追加する実験も動作した。**投票後の数値はすべてシミュレーション**であり、実際の人気変化・投票量・遺伝子効果・臨界点ではない。

### 初期価格のみ実測、以後は架空の投票者ABM

実装：scripts/ecology_market_voter_abm_anchor.py  
シミュレーション結果：docs/evidence/market-9-real-initial-conditions-synthetic-voter-20261115.json  
GitHub Actions：https://github.com/zuizui0223/keiba/actions/runs/43697398731  
13件の専用テスト（市場クロスセクション7件、ABM6件）合格。

初期9レースのqを観測値として使用。各仮想レースの初期プール1000票、250票/バッチ×20更新、40独立seedで4仮説×9レース×40=**1,440本の架空軌跡**を生成。

投票者の新しい架空選択確率：

    P(voter selects horse i at step t) ∝
        q_initial,i * exp{ rho(t) * log[q_current,i / q_initial,i] }

q_currentは過去までの**架空の累積投票**。市場で観測された元のオッズを変えているのではない。

| 架空の意思決定規則 | 仮想20バッチ後の平均有効支持頭数 | 元1番人気が他馬に逆転される架空軌跡割合 |
|---|---:|---:|
| 客観的初期支持率のみ（ρ=0）|7.8501|15.8%|
| 人気への比例追随（ρ=1）|7.8246|21.4%|
| 強い滑らかな追随（ρ=2）|7.7758|40.6%|
| 変化閾値を超えたら追随（ρ=0→2, |Δlogq|>0.07）|7.7819|38.9%|

**この数字は実競馬の「逆転率」ではない。** 4モデルの**仮説に対する数理的感度例**である。閾値＝0.07は任意の実装パラメータであり、実世界の臨界オッズも実測された投票行動も識別していない。ごく少数の開始レース、架空票数、同一seedの共通乱数を使うため、統計的な有意差は議論しない。

## 本来検定すべき生態学と市場の同時モデル

1. 客観競走能力モデル：遺伝的期待関連Aや検体ID対応G/遺伝子型、距離・馬場×遺伝子型、年齢・厩舎・馬場条件。能力が未来着順や初期速度を予測するか。
2. **初期市場モデル**：初期qの予測に「本人過去履歴＋競馬場・天候・騎手情報」の基準を置き、公開血統の評判・父母実績を追加。最初のオッズを最初のオッズの説明変数に使わない。
3. **継続市場モデル**：既知のq(t)とΔqと新情報を基準に、出走前既知血統が将来のq(t+Δ)に追加予測力を持つか検定。連続モデルと閾値モデルを**同じ日付分割で比較**。
4. **市場効率モデル**：当時の単勝オッズのみの予測に血統・実測遺伝子情報を追加して、未来勝敗のproper score（対数損失／Brier）が下がるか。勝利期待値と払戻・テイクアウトは別。
5. **育種と進化の帰還**：種牡馬価格・1歳馬セリ価格・公開人気→交配頻度、配合選択・子世代SNP/MSTN頻度・近交係数の変化を世代追跡。人気の遺伝的価値過大評価と健康・多様性のトレードオフを分離。

**採用条件:** 同一のrace_id×登録horse_id×公式時刻と取消込み出走頭数の3時点以上の完全単勝時系列、血統の父母ID及び事前情報時刻。公開血統の評判と個人実測MSTNは分け、匿名370頭SNPを馬名へ無理に結合しない。初期支持率・将来オッズ・実結果を一つのラベルにしない。投票量が不明なら社会的追随・投票者数の絶対係数は識別不能となり得る。

今回の証拠を使って実市場の臨界点、血縁が市場を歪めた効果、競走馬の適応遺伝子の当該馬での効果、収益性を主張することはできない。**PR #47はドラフト維持、v3.1の既存holdout基準を変更しない。**
