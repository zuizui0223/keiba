# 2022→2024 親族情報ルールの予測失敗を構成変化と条件付き効果変化に分解

**2026-11-18：すでに2022〜24年の全スコア・年別の逆転を見た後の事後的機構診断。** この設計に基づく2023/24の分解を未開封の独立検証と呼ばない。データ源が同じため、新規の前向き競走・ゲノム因果・市場追随を主張しない。

## 元の反証事実

厳密な完全順位35,333レース、12,887頭、244,147出走を固定。2018–21年Source Aで既に学習済みのM1（本人履歴＋条件）／M2（M1＋同父/同母の他馬履歴）を利用する。2022年だけで選んだMGゲートは「本人の2021年以前の有効過去走数≤15、かつ同父/同母の他馬に同環境セルの有効記録が1頭以上あればM2、それ以外はM1」。2022年はMGがM2を上回るが、2023・2024年はM2が上回り、2024年にはMGもM2も中間順位M0に負けた。

今回の問いは、「2022年のMGの追加価値が2024年までに失われた理由は、**2024年に別の情報量の馬が多く出走したこと（構成変化）**で説明できるのか、あるいは**同じ情報量区分の馬でも親族モデルの相対誤差が変わったこと（区分内の変化）**なのか」。

## 完全に固定した二つの説明量

本人のSource A有効過去走数の四区分 \(b\)（0–3、4–7、8–15、16+）を**同一ソースで2021年以前に決定**。これは公式の初出走を表さない。区分は既存研究から引き継ぎ、新たに肯定方向を得るための閾値最適化はしない。

各年 \(y\) の同一馬内の出走数を \(n_{iy}\) とし、観測重み \(a_{iry} = (1/n_{iy}) / N_y\) を使う。ここで \(N_y\) はその年に出走した異なる焦点馬の頭数。出走単位の正規化順位の正解 \(z_{iry}\)、固定M2予測 \(\hat z_2\)、固定MG予測 \(\hat z_G\) に対し、

\[
d_{iry} = (z_{iry}-\hat z_{2,iry})^2 -
          (z_{iry}-\hat z_{G,iry})^2.
\]

正値はゲートMGが常時親族M2より良い。年ごとの全体MSE差 \(D_y=\sum_{ir} a_{iry}d_{iry}\) は**同一馬均等重みのリスク差**であり、RMSEの差ではない。

区分 \(b\) の年内馬均等重み割合を \(w_{yb}\)、その区分での重み付きMSE差を \(\delta_{yb}\) とすると、恒等的に \(D_y=\sum_b w_{yb}\delta_{yb}\)。2022年を固定参照にして、

\[
\begin{split}
D_y-D_{22}
&=\sum_b (w_{yb}-w_{22b})\delta_{22b}\\
&\quad+\sum_b w_{yb}(\delta_{yb}-\delta_{22b}).
\end{split}
\]

第1項を「**2022年の区分内効果が固定の場合、出走構成だけが変わる寄与**」、第2項を「**その年の出走構成を固定した区分内の予測誤差差の変化**」と呼ぶ。正負の構成要素が打ち消し合う可能性があり、寄与率を必ず0〜100%に押し込まない。

同じ区分でも馬齢、牧場、競走相手、距離、年度、出走選択・引退などが変わるため、**この第2項は因果的な環境効果や個体内の老化効果ではない**。第1項も生存・繁殖率そのものではない。本人の記録区分の違い以外の集団構成変化は第2項に残る。

## 判定

2024年のMGの悪化の説明要素を定量化し、最も割合の大きい項を**記述的に**同定する。いずれかが負なら、その符号を修正しない。構成変化が小さくても「年効果の因果」とはしない。検証すべき次の予測は、真の公式IDで将来レース前に個体歴と他馬歴を収集し、M0/M1/M2/MGの事前固定ルールが複数年で安定するかどうかである。
