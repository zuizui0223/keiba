# 🐎 keiba — Racehorse behavioral ecology & odds-methods research

**中心テーマは、競走馬の個体差を生態学的に検証すること。**
公開された元の馬IDとGPS区間データを使い、
同じ馬の過去の走り方が後の走り方をいつ説明できるか、
そして環境・競争相手・時間を越えて一般化できるかを調べます。

**馬券・オッズの予測は別系統です。** 収益モデルや
勝率の証明を、生態学的な個体差の根拠に使いません。

## 2026-11-18：実データの血縁・ゲノム・情報・市場を統合

**[統合研究レビュー（個体情報・血縁・ゲノムG・オッズ市場と情報の時間階層）](docs/research/INTEGRATED_KINSHIP_GENOME_INFORMATION_MARKET_20261118.md)** に、実際に測定された肯定結果、同じデータの事後感度分析、負の結果、将来モデルの合成テストを区別して整理しました。

日本2019–21の本人履歴不足時の親族情報、2022–24の小さい条件付き改善、2026年の本人履歴更新の大きな効果と当初の独立期間予測の失敗、Wikipediaの**欠損の大きい部分系譜A**、匿名370頭の実SNP由来**G**、9レース117頭の**単一スナップショットでの市場集中度**を、それぞれ独立した証拠として扱います。**全国の完備したJRA/NAR血統、同一馬のA×G×成績、真正の時系列市場の閾値、2027年実予測と遺伝的因果は未検証です。**

**[新しい数理検証：個体情報と親族情報の精度階層](docs/research/INFORMATION_PRECISION_HIERARCHY_ECOLOGY_20261118.md)** では、実データの肯定・否定結果を再照合したうえで、本人の観測回数・親族情報の古さ・共有環境による冗長性から、親族情報の追加価値がいつ減るかを解析的に導いています。**理論数値は架空のパラメータであり、遺伝的因果・実際の市場追随ではありません。**

**[2022〜2024年・親族情報が役立つ条件の実測層別](docs/research/JAPAN_2022_2024_KIN_INFORMATION_MODERATORS_RESULTS.md)**：厳密な244,147出走で、本人の記録が0〜3走なら親族履歴の追加RMSE改善が約+0.000871、16走以上では約−0.000070。ただし**2024年はその順序が逆転し**、親族記録の古さに単調な減衰は見えない。既存の2022–24/2026結果を見た後の**事後分析**であり、遺伝的因果・市場への影響や2027年の未来予測ではありません。

**[2022年選択の親族情報ルールの2023・2024年への転移検証](docs/research/JAPAN_2022_KIN_GATE_2023_24_TRANSFER_RESULTS.md)**：2022年だけで「本人15走以下＋共通父母の他馬記録ありならM2」という使い分けを選ぶと、選択年は親族常用モデルよりわずかに良い一方、**2023・2024年には常用M2より悪化し、2024年は中間順位M0にも負けた**。実データの結果を見た後の**事後的な年順転移診断**であり、真正の2027年独立予測ではありません。

**[親族情報の利用ルールが年を越えて失敗する理由の分解](docs/research/JAPAN_2022_24_GATE_FAILURE_DECOMPOSITION_RESULTS.md)**：同じ244,147出走を用い、2022→24年の親族ゲートの悪化を分解。本人の過去走数4区分の構成変化だけで約5.7%、区分内変化が約94.3%。2024年にも出走する5,163頭の選択に対応する差が約42.3%、同じ候補馬の年別誤差差変化が約57.6%。**すべて事後的な記述的MSE分解であり、継続出走＝生存/適応度や遺伝的因果の証明ではありません。**

**[2022→24年・同一馬×馬場・距離帯の追検証](docs/research/JAPAN_2022_24_MATCHED_CONTEXT_RESULTS.md)**：共通条件の**4,777頭**で2022年構成を固定すると、MG対M2の馬均等MSE差の変化は**−0.00007088**。馬単位399回の95%感度区間 **[−0.00018658, +0.00002707]** は0を含み、一般的な時間減衰・遺伝因果はHOLD。

**2026-11-21進捗**：[MG情報切替率](docs/research/JAPAN_2022_INFORMATION_SWITCH_EXPOSURE_RESULTS.md)の−16.56ポイント差は本人履歴構成を揃えると+0.033ポイントへ縮小。2027年向けに[結果欠測・全予測分母の監査](docs/research/JAPAN_2027_FROZEN_UNIVERSE_RANK_BOUNDS_RESULTS.md)と[対象レース一覧自体のGitHub事前封印](docs/research/JAPAN_2027_IMMUTABLE_UNIVERSE_PLEDGE_RESULTS.md)を実装。**94件の架空試験成功、実馬の2027年予測0件。** 血統の遺伝因果・死亡・引退はHOLD。

**[父方・母方の親族成績](docs/research/JAPAN_2022_24_PARENT_PERFORMANCE_CHANNELS_RESULTS.md)**：父方のみ対母方のみの通期の馬均等MSE改善は+0.00008239。12比較調整区間は全て0を含み、2024年は全6学習モデルで中間順位より誤差が大きい。

## 原GPS研究の現在地（2026-10-18当時の基準）

| 確認できたこと | 現時点で言えないこと |
| --- | --- |
| Cannon Parkの元資料36馬ID・後続46記録で、**その馬自身の過去の初期GPS相対タイム履歴**（RMSE 0.255809秒）が、同条件の**他馬履歴**（0.303195秒）より後続記録を説明した | 先天的な「性格」・遺伝率・実際の騎手変更の因果効果 |
| Doombenでは別々の年内・年越し解析で正負の予測結果が得られた | **同じ馬の個体性が年越しで弱まった**という解釈。両方を評価できた同一馬は元資料条件下で**0頭** |
| 馬場と送信元名簿の反復・欠測状況を監査し、H1とH2の解析方法をシミュレーションで検証した | **H1：馬×馬場の反応規範、H2：他馬との因果的相互作用**。実馬の必要な反復・確定出走・完走タイム情報が不足し、科学的に**HOLD** |

適応進化、馬券の的中確率を実証したものではありません。
